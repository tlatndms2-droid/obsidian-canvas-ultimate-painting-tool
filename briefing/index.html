03. 사용자가 누르는 것과 결과

상황사용 방법문서상 기대 결과
카드를 조작할 때Selection 도구 선택기존 Canvas처럼 카드를 선택·이동·크기 조절합니다.
그림을 그릴 때브러시 선택 → 마우스 또는 펜 드래그현재 레이어에 그립니다. 레이어가 없으면 Layer 1을 자동 생성·선택합니다.
그리다가 화면 이동Space + 왼쪽 드래그 또는 휠 클릭 드래그Canvas를 이동합니다. Space를 놓아도 사용하던 그리기 도구는 유지됩니다.
확대·축소마우스 휠화면을 확대·축소해도 그림과 카드의 상대 위치를 유지합니다.
브러시·지우개 크기Ctrl + Alt + 좌우 드래그크기가 연속으로 바뀌며 커서에 실제 직경을 표시합니다.
일부만 지우기지우개 → 그림 일부에 드래그현재 레이어의 닿은 부분만 지웁니다. 잠긴 레이어는 편집하지 못합니다.
그림 일부 변형사각형·올가미로 영역 선택 → 변형현재 레이어의 선택 영역을 이동·확대·축소·회전·반전·삭제합니다. 바깥 클릭은 선택 해제입니다.
복사·붙여넣기Ctrl+C / Ctrl+X / Ctrl+V붙인 그림은 현재 레이어에 들어가며 즉시 선택됩니다.
실행 취소·복구Ctrl+Z / Ctrl+Shift+Z그리기·지우기·도형·문자·레이어 작업을 시간순으로 되돌리는 것이 목표입니다. 기존 Canvas 기록과의 완전 통합은 미검증입니다.

도형과 문자

직선·사각형·원·타원·직선 화살표는 채우기 없이 외곽선만 그립니다. 생성 후 위치·크기·선 굵기·색을 바꿉니다.

화살표·직선은 양 끝점도 조절합니다. 문자는 클릭한 위치의 현재 레이어에 생성하고 내용·크기·색·위치를 수정합니다.

레이어 정리

생성·삭제·이름 변경, 표시·숨김, 잠금, 불투명도, 순서 변경, 그룹, 합치기를 지원하는 기획입니다.

위 레이어가 앞에 표시되며, 삭제·합치기는 되돌릴 수 있어야 합니다. 실제 그림 축소 미리보기를 표시하는 것이 목표입니다.

선택의 대상 구분

카드 조작: 기존 Canvas 조작으로 복귀합니다.

그림 편집: 선 하나씩보다 사각형·올가미로 둘러싼 영역을 선택합니다.

두 선택 동작을 어떤 하위 버튼으로 연결할지는 원문만으로 확정하기 어렵습니다.

04. v2에서 특히 중요한 브러시와 색 혼합

설정 골격 확정

브러시 설정은 9개 범주

크기잉크색 혼합브러시 끝 모양획손떨림 보정질감분사·흩뿌리기입력에 따른 변화

크기는 슬라이더·숫자 입력·단축 조작으로 바꾸며, 최소 크기와 필압 곡선을 포함합니다. 필압에 따른 크기·불투명도 변화는 각각 켜거나 끄고 강도를 조절합니다.

손떨림 보정은 브러시별로 저장합니다. 그룹·순서·설정도 프리셋으로 관리합니다.

범주가 확정되었다고 모든 세부 설정의 구현이 확정된 것은 아닙니다.
핵심 목표 · 구현 방식 미검증

이미 칠한 색과 새 색이 섞이기

예를 들어 파란색 위에 노란색 브러시를 움직이면, 두 색이 물감처럼 상호작용하는 경험을 목표로 합니다. 실제 혼합 색과 결과는 아직 확정되지 않았습니다.

물감 양·밀도·색 끌림·혼합 방식 등을 검토합니다. 불투명도는 물감의 양·밀도와 별도로 다룹니다.

Clip Studio Paint와 같은 내부 방식이나 동일 결과를 보장하는 기획은 아닙니다.

Photoshop 브러시 가져오기
파일 가져오기 → 지원 가능한 속성 확인 → 이 플러그인의 설정으로 변환 → 일반 프리셋과 함께 사용. 가져오기 자체는 목표지만 완전 호환과 모든 속성 변환은 확정되지 않았습니다.

05. 저장·연결·성능은 어떻게 다루는가

그림은 별도 데이터로 연결

Canvas 파일에 그림 데이터를 무제한으로 쌓지 않고 별도 그림 자료와 연결합니다. 구체적인 파일 형식과 저장 위치는 아직 정하지 않았습니다.

그리기 → 화면에 즉시 반영 → 변경분 모으기 → 자동 저장

Canvas 전환·닫기·앱 종료 때 남은 변경도 저장하는 요구사항입니다. 펜이 움직일 때마다 디스크에 저장하지 않습니다.

그림이 많아져도 탐색 유지

화면 주변을 우선 표시하고, 멀리 축소했을 때는 표시만 단순화합니다. 다시 확대하면 원래 품질을 복구하며 원본 데이터는 유지합니다.

숨긴 레이어와 작은 미리보기의 불필요한 갱신을 줄이고, 화면 이동 때 전체 그림을 매번 다시 만들지 않는 방향입니다.

CPU·GPU·메모리·저장 공간·화면 반응성의 실제 비용은 미측정입니다. 네트워크 사용 정책도 이 자료에 명시되어 있지 않습니다.
Canvas에 하는 일연결된 그림의 상태
복제그림도 독립 복제합니다. 복제본을 바꿔도 원본과 별도로 유지합니다.
이름 변경·이동기존 그림과의 연결을 유지합니다.
삭제연결된 그림 데이터도 삭제하는 정책입니다. 플러그인 자체의 고아 데이터 보존 기능은 두지 않습니다.
연결 해제별도 사용자 기능이나 이후 보존 정책은 이 자료에 정의되어 있지 않습니다.

원문이 요구하는 첫 관문: Canvas 연동 소규모 검증

본격적인 브러시 개발 전에 아래 동작이 함께 성립하는지 확인하도록 되어 있습니다. 이번 브리핑에서는 실행하지 않았습니다.

직접 그리기 → 이동·확대 시 위치 유지 → 카드 입력 충돌 확인 → 저장·재실행 복원 → 대형 Canvas 성능 확인

추가로 그림 한 획마다 Canvas 항목을 하나씩 만드는 구조를 피하는지도 확인 대상입니다. 원문은 이 관문을 통과해야 후속 개발로 넘어가고, 실패하면 Canvas 연동 구조부터 다시 검토하도록 정합니다. 필요하면 색 혼합도 별도로 검증합니다.

  • 레이어 복제 기능과 별도 그림 복제 명령

  • 브러시의 개별 획 선택을 기본으로 하는 방식
