# UI SPEC --- Confirmed UI

## 핵심

Obsidian Canvas 자체가 Drawing Surface다. 별도의 Drawing 화면을 만들지
않는다.

## 기본 배치

`좌측 Drawing Toolbar → Toolbar 오른쪽 Context/Brush Panel → 중앙 전체 Canvas → 우측 Layer Panel`

## Drawing Toolbar

-   Canvas 좌측
-   세로형
-   Selection / Brush / Eraser / Shape / Text / Color / Eyedropper /
    Undo / Redo

## Brush Preset Panel

-   Brush 버튼과 연결
-   Toolbar 오른쪽에 표시
-   Brush Group
-   Stroke Preview
-   Brush Name
-   선택 Preset Highlight
-   Brush 추가
-   Group 추가
-   삭제
-   Brush Settings 접근
-   Group 생성/삭제/이름 변경
-   Group 접기/펼치기
-   Preset 순서 및 Group 간 이동
-   Photoshop Import Brush도 동일 Panel에서 관리

## Layer Panel

-   Canvas 우측
-   Photoshop/CSP식 Layer Workflow 참고
-   Visibility
-   실제 Drawing Thumbnail
-   Layer Name
-   Lock
-   선택 Highlight
-   Opacity

## Mockup 규칙

새 UI는 가능한 경우 Obsidian Canvas 전체 맥락에서 HTML로 표현한다. 기존
확정 위치를 임의 변경하지 않는다.
