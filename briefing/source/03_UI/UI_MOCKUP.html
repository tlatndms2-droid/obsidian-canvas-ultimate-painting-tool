Canvas Drawing Tool Bar

Obsidian Canvas 자체를 그림판으로 확장하고, Clip Studio Paint에 가까운 Drawing 경험을 제공하되 기존 Canvas 성능과 사용성을 희생하지 않는다.

Canvas = Drawing Surface

별도 Drawing Canvas/Area 없음. Card, Image, Group과 Drawing이 같은 Canvas 공간에 공존.

CSP-oriented UX

Brush, Layer, Selection, Transform, 필압, Stabilization을 실제 Drawing 작업 수준으로 설계.

P0 Performance

Pan/Zoom/Card 조작과 대형 Canvas 탐색 성능 보호.
