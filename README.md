# Obsidian Canvas Drawing Tool Bar

Obsidian Canvas 위에서 그림을 그리는 도구의 기획 자료와 구현 가능성 시험 소스입니다.

- **최신 기획 묶음:** [2026-10-01 최종 Planning Pack](planning-packs/Canvas_Drawing_Tool_Bar_FINAL_Planning_Pack_2026-10-01.zip)
- `planning/`, `briefing/`, 루트 `HANDOFF.md`는 그 이전의 작업 기록입니다. 최신 기획과 충돌할 때는 위 Planning Pack의 후속 결정 문서를 확인하세요.
- `poc/`는 기술 시험용 코드입니다. 시험 중 생성된 증거·백업과 설치 도구 파일은 저장소에 포함하지 않습니다.
- 기획 사이트는 별도의 Sites 저장소에서 관리합니다.

ZIP 안의 문서는 참고 자료이며, 실제 작업 범위는 사용자의 현재 요청으로 정합니다.
