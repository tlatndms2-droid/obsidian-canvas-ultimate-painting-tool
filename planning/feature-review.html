05 / 범위와 다음 확인

확정하지 않은 것을 숨기지 않습니다

색 혼합의 결과

물감처럼 섞이는 기능은 핵심 목표입니다. 현재 레이어만 섞을지, 아래 레이어도 참고할지는 아직 답변 전입니다. CSP와 같은 품질·필감은 보장할 수 없습니다.

Photoshop 브러시 호환

가져온 브러시를 일반 프리셋으로 쓰는 방향입니다. ABR 지원 버전·속성별 변환·결과 유사도는 샘플 파일로 확인해야 합니다. 완전 호환 확정은 아닙니다.

전체 화면 스포이드와 Undo

스포이드 API 존재는 확인했지만 실제 카드·이미지 색 선택은 미시험입니다. 그림 내부 Undo는 설계 가능하고, Obsidian 카드 작업과 하나의 순서로 합치는 것은 별도 확인 대상입니다.

대형 그림과 데이터 정리

1,500획 실험에서 화면 이동 반응 저하가 남았습니다. 최적화와 휴지통 영구 삭제 후 정리는 해당 기능 개발 때 검증합니다.

다음 검증은 기능 기획이 달라지는 의문에 한정합니다. 기존 Canvas 연동을 반복 시험하지 않고, 미확정 기능의 원하는 결과부터 정합니다.

이번 기획에서 제외

별도 Drawing 화면 · 한 획마다 Canvas 카드 생성 · 레이어 복제 · 별도 그림 복제 명령 · 도형 채우기 · 기본 조작으로 개별 획 선택 · 플러그인 자체 고아 그림 보존 기능. 휴지통 정리 정책은 충돌을 해결하기 전까지 추가 확정하지 않습니다.

실행 비용 전망

측정 전 예상: 도구·프리셋 UI는 CPU·메모리 부담 낮음. 큰 그림·여러 레이어·색 혼합은 CPU/GPU·메모리·저장 공간 부담 중간~높음. 저장 데이터와 화면 반응성은 획 수·면적·레이어 수에 따라 달라집니다. 핵심 로컬 그리기에 네트워크는 필요하지 않습니다. 이 HTML은 외부 글꼴·라이브러리 없이 파일 자체로 열립니다.
