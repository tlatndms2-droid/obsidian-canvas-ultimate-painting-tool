# 5단계 — 화면·상태·데이터 관계 설계 (검토용 초안)

[기능별 동작](04_FUNCTION_DESIGN.md)을 실제 Obsidian Canvas 화면에 놓은 설계 초안이다. [조작 가능한 HTML 시안](05_UI_MOCKUP.html)은 배치와 상태를 확인하기 위한 모형이며 플러그인 구현이나 기능 검증 결과가 아니다. **기존 자료에서 정한 위치**와 **이번에 제안한 세부 동작**을 분리해 적는다.

## 1. 화면 전체

```text
Obsidian 파일/Canvas 화면
┌───────────────────────────────────────────────────────────────────────┐
│ Canvas 이름                                             기본 Canvas UI │
│ ┌──────┐ ┌──────────────────┐ ┌───────────────────────┐ ┌──────────┐ │
│ │그림  │ │선택 도구의 설정  │ │ Obsidian Canvas        │ │그림      │ │
│ │도구  │ │또는 브러시 목록  │ │ 카드·이미지·그림       │ │레이어    │ │
│ │막대  │ │                  │ │                       │ │패널      │ │
│ └──────┘ └──────────────────┘ └───────────────────────┘ └──────────┘ │
└───────────────────────────────────────────────────────────────────────┘
```

Canvas 전체가 그리기 공간이다. 별도 그림 창을 열지 않는다. 왼쪽 세로 Drawing Toolbar, 그 오른쪽 Context/Brush Panel, 오른쪽 Layer Panel은 기존 UI 자료의 **확정된 배치**다. 패널 폭·아이콘 모양·접기 버튼·색상은 이번 시안의 제안이다. 실제 Obsidian의 기존 Canvas 조작 버튼을 가리지 않는 위치는 구현 화면에서 비교해야 한다.

## 2. 왼쪽 도구 막대

| 누르는 것 | 누른 직후 보이는 것 | Canvas에서 다음 입력 | 근거/상태 |
|---|---|---|---|
| 카드 선택 | 선택 아이콘 강조, 브러시 패널은 화면에 남음 | 카드 클릭·이동 등 Obsidian Canvas 조작 | 카드와 그림 도구 구분·패널 유지 사용자 결정 |
| 브러시 | 브러시 강조, 오른쪽에 프리셋·크기·색/혼합 설정 | 누르고 끌면 활성 레이어에 선 | 기존 요구, 세부 배치는 제안 |
| 지우개 | 지우개 강조, 크기·불투명도/압력 표시 | 활성 레이어의 닿은 그림 부분을 지움 | 기존 요구, 세부 값 미정 |
| 사각형/올가미 | 선택 도구 강조, 선택 작업 막대 표시 | 현재 그림 레이어의 영역 지정 | 선택 시작 방식 사용자 확정 |
| 도형 | 직선/사각형/원/타원/화살표 하위 목록 | 드래그하여 외곽선 생성 | 기존 목표, 정확한 조작 제안 |
| 문자 | 글꼴·크기·색 표시 | 클릭한 위치에서 텍스트 입력 | 기존 목표, 편집 UI 미정 |
| 색/스포이드 | 현재 색 또는 스포이드 상태 표시 | 새 색 고르기/화면에서 색 찍기 | 기존 목표, 샘플 규칙 미정 |
| Undo/Redo | 실행 가능할 때만 선명한 버튼 | 그림 편집 한 단위씩 되돌림/다시 실행 | 목표, Obsidian 기본 Undo와의 관계 미정 |

도구를 바꿀 때 기존 그림은 유지된다. 단축키가 기존 Canvas 명령과 겹치면 어느 쪽이 작동하는지 명시해야 한다. 도구 막대의 선택 강조는 색뿐 아니라 테두리/이름으로도 알 수 있게 한다. 잠긴 레이어에서 브러시·지우개를 쓰면 선이 나타나지 않고 `레이어 잠김`을 잠깐 보여주는 것을 제안한다.

## 3. 브러시 패널과 설정

**브러시 선택 흐름:** 브러시 아이콘 → 프리셋 그룹 펼침 → 선 미리보기와 이름을 보고 선택 → 상단의 현재 브러시·크기·불투명도 확인 → Canvas에 그림. 선택한 항목을 강조한다. 그룹 만들기·이름 변경·접기·순서 변경·그룹 간 이동과 ABR 가져오기는 같은 패널에서 시작한다.

| 영역 | 보이는 내용 | 사용자 행동 후 변화 |
|---|---|---|
| 패널 상단 | 현재 도구 이름, 설정 열기, 패널 접기 | 설정을 열면 선택한 프리셋의 세부 값을 표시 |
| 그룹 목록 | 그룹 이름, 접기 화살표, 프리셋 수 | 그룹을 접어도 프리셋은 삭제되지 않음 |
| 프리셋 행 | 획 미리보기, 이름, 선택 강조 | 선택 즉시 다음 획에 적용 |
| 빠른 조절 | 크기, 불투명도, 현재 색 | 값 조절 즉시 다음 획에 반영 |
| 색 혼합 | 켜기/끄기, `현재 레이어`/`보이는 그림 레이어` | 다음 획의 색 참조가 바뀜; 기본 범위는 현재 레이어 |
| 관리 메뉴 | 브러시 추가, 그룹 추가, ABR 가져오기, 삭제 | 이름/대상 확인 뒤 목록 변경 |

세부 설정의 9개 범주는 기존 요구의 **목표 목록**이다. 한 화면에 전부 펼치지 않고 범주별 접기 또는 탭으로 찾게 하는 것을 제안한다. 현재 조절값은 그 도구를 다시 선택할 때와 Obsidian 재시작 후에도 유지한다. `기본값으로 저장`은 원래 기준값을 별도로 정하는 동작이다. 같은 Vault의 다른 Canvas에서도 프리셋을 사용할 수 있다. 시안은 실제 프리셋 저장을 실행하지 않는다.

**ABR 가져오기 화면 제안:** 파일 고르기 → 브러시별 미리보기/이름/지원 상태 목록 → 가져올 항목 선택 → 결과 요약 → 프리셋 목록에서 확인. 미지원 속성을 무시했다면 각 브러시 행에 알아볼 수 있는 안내가 필요하다. 시험한 일부 ABR의 동작만 확인된 상태이므로 `모든 ABR 지원` 문구는 쓰지 않는다.

## 4. 오른쪽 레이어 패널

| 위치/상태 | 보이는 것 | 누르면 생기는 일 |
|---|---|---|
| 패널 머리글 | `그림 레이어`, 추가 버튼, 패널 접기 | 새 레이어가 목록에 생겨 선택됨 |
| 레이어 행 | 눈 아이콘, 실제 그림 썸네일, 이름, 잠금 아이콘 | 행 클릭으로 활성화, 눈으로 표시 전환, 자물쇠로 편집 차단 |
| 선택 행 | 테두리와 배경으로 강조 | 브러시·지우개·영역 편집의 대상이 됨 |
| 위쪽 조절 | 활성 레이어 불투명도와 혼합 모드 자리 | 화면의 겹침 결과가 바뀌고 다른 레이어 원본은 유지 |
| 행 메뉴 | 이름 변경, 순서 변경, 삭제; 그룹/합치기 목표 | 실행 전에 대상을 알 수 있고 삭제·합치기는 Undo 대상 |
| 빈 Canvas | `아직 그림 레이어 없음`과 첫 그림 안내 | 첫 선에서 `Layer 1` 자동 생성 |

실제 그림 내용 썸네일은 목표이나 많은 레이어에서도 화면 이동과 그리기 반응성을 해치지 않아야 한다. 레이어는 카드보다 항상 앞에 놓인다. 숨김/잠금 상태와 선택 상태를 혼동하지 않도록 아이콘·문구·행 강조를 동시에 사용한다. 비어 있는 마지막 레이어 삭제와 잠긴 레이어를 선택한 뒤 그림을 시도한 경우의 정확한 문구는 후속 검토다.

## 5. Canvas 위 피드백

| 작업 | 작업 중 화면 | 끝나거나 취소했을 때 |
|---|---|---|
| 브러시 | 커서 근처 크기 윤곽, 입력을 따라 선 미리 표시 | 선은 카드보다 앞에 남고 현재 레이어 썸네일 갱신 |
| 지우개 | 지우는 영역 윤곽, 닿은 부분 변화 | 현재 레이어 내용만 수정 |
| 사각형/올가미 | 선택 테두리와 영역 안 강조 | 선택 작업 막대 표시; 해제 시 테두리 사라짐 |
| 변형 | 조절점과 이동 결과의 임시 표시 | 적용하면 변경 저장, 취소하면 원래 모습 |
| 도형 | 드래그 중 외곽선 미리보기 | 확정 후 다시 선택·수정 가능해야 함 |
| 문자 | 편집 중 입력 상자 | 확정 후 글이 그림 레이어에 표시 |
| 저장 | 평상시 상시 배너 없이 자동 저장 | 저장 오류에만 분명한 상태와 다시 시도 동작 필요 |

선택 작업 막대의 정확한 위치, 도형/문자 재선택 방식, Undo와 Obsidian 카드 작업의 순서는 확정하지 않았다. 이들은 HTML 모형이 보여주는 배치보다 실제 사용 흐름과 데이터 결과를 먼저 맞춰야 한다.

## 6. 화면 상태와 데이터 범위

| 사용자가 보는 것 | 저장되는 범위 | Canvas A에서 바꾼 뒤 Canvas B를 열면 |
|---|---|---|
| 그림 내용·레이어 순서·이름·표시·잠금·불투명도 | 해당 Canvas의 그림 자료 | B 자체의 그림과 레이어가 보임 |
| 브러시 프리셋·그룹·가져온 ABR | 같은 Vault의 공용 자료 | 같은 프리셋을 고를 수 있음 |
| 현재 도구·현재 색·패널 열림 | 현재 색은 같은 Vault의 다른 Canvas에서도 이어 사용. 브러시 마지막 조절값은 재시작 후 유지. 현재 도구·패널 열림의 재시작 유지 범위는 미정 | 색은 이어 사용하고 B의 그림·레이어는 독립; 도구·패널 상태는 후속 결정 |
| Canvas 카드·이미지·그룹 | Obsidian Canvas 본래 자료 | B에 저장된 카드만 보임 |
| 카드 전용 그림 | 선택한 카드에 붙은 그림 자료 | 같은 파일의 카드가 다른 Canvas에 있어도 카드마다 독립 |

`작업.canvas`를 복제하면 그림도 복제하되 이후 편집은 독립이다. 이름 변경·폴더 이동 후 연결을 유지한다. 플러그인을 끄거나 제거해도 그림 자료를 보존하고 다시 켜면 표시한다. Obsidian 내부 휴지통과 Windows 휴지통에서 Canvas를 복원하면 그림도 돌아와야 한다. 저장 파일의 이름·형식은 구현 선택이며 이 화면 설계에서는 고정하지 않는다.

## 7. 화면 설계에서 남은 결정

기존 확정 위치를 바꾸지 않는 범위에서 대부분은 CSP의 일반적인 조작을 기준안으로 계속 구체화한다. 다만 아래는 사용자에게 보이는 결과가 크게 달라진다.

1. **프리셋 수정의 저장:** 마지막 조절값의 재시작 후 유지는 사용자 결정이다. 현재 값과 별도 기본값의 화면 표시, 기본값으로 되돌리기 조작은 상세 UI 설계가 남았다.
2. **그림 선택·변형의 취소/Undo:** 선택 직후 조절점 표시·안쪽 드래그 이동·모서리 크기 변경·영역 밖 클릭 해제는 사용자 결정이다. 변형을 취소하거나 Undo할 때 어느 범위가 되돌아가는지만 더 정리한다.
3. **스포이드 범위:** 카드·이미지·그림이 겹친 픽셀에서 화면에 보이는 최종 색을 찍는지, 그림만 찍는지. 기존 목표는 화면에 보이는 결과지만 일부 화면 상태는 미검증.
4. **레이어 삭제/합치기:** 실행 전 확인, 결과 레이어 이름·순서, Undo 단위. 그룹·합치기의 버전 범위는 기능 설계 뒤 재검토.
5. **저장/복구 안내:** 저장에 실패했을 때 수정 내용을 어떻게 보여주고 다시 저장하게 할지.

**현재 판정:** 위치와 핵심 화면 구조는 기존 자료와 일치하도록 정리했다. 버튼별 대표 상태와 Canvas/Vault 데이터 범위를 초안으로 연결했다. HTML은 조작을 상상하기 위한 시안이다. 위 결과 차이와 도형·문자·선택의 세부 화면이 남아 있으므로 **5단계 진행 중**, 전체 기획 완료 아님.

## 8. 2026-09-29 후속 화면 설계 — 그리면서 카드를 선택한다

기존 왼쪽 그림 도구막대에 **`그릴 카드`라는 독립 도구를 추가하지 않는다**. 그리기 도구를 쓴 채 카드 선택 가능 상태를 켜고 끄는 UI는 도구 설정 영역에 둔다. 이 상태는 브러시·지우개 등 그림 도구 선택과 독립적이다. 카드 클릭은 선택만 하며 이동은 기존 카드 선택 도구에서만 한다.

```text
왼쪽 그림 도구 선택 → 그리기 설정에서 ‘그리면서 카드 선택’ 켜기
→ 카드 클릭(이동 없음) → 카드 바로 위 기존 메뉴바 표시
→ 그 메뉴의 ‘선택한 카드만 그리기’ 켜기 → 해당 카드 안에 그림
```

| 화면 상태 | 선택 카드 | 카드 위 메뉴 | 다음 그림 | 이미 있던 Canvas 그림 |
|---|---|---|---|---|
| 기본 그리기 | 없음 | 없음 | 카드 위를 덮어 Canvas 전체에 그림 | 카드 앞에 표시 |
| 그리면서 카드 선택 | 클릭한 카드 | 해당 카드 바로 위에 표시 | 카드 전용 토글 전에는 Canvas 전체 그림 | 선택 뒤에도 카드 앞에 표시 |
| 선택한 카드만 그리기 | 한 카드 | 해당 카드의 토글 켜짐 | 해당 카드 내부에만 그림 | 사라지거나 카드 아래로 내려가지 않음 |
| 기존 카드 선택 도구 | 일반 Obsidian 선택 카드 | 기본 카드 메뉴 | 그리기 대신 카드 이동 | Canvas 그림은 원래 Canvas 좌표에 남음 |

카드 안의 그림은 카드와 이동·크기 변경을 함께한다. 그림이 있는 카드 삭제/Undo·복제에도 카드와 함께 처리하되 복제본은 독립이다. 같은 파일을 두 카드로 놓아도 서로의 그림은 공유하지 않는다. 글 내용만 달라지면 그림은 카드 안의 같은 위치에 남는다. 글·이미지·파일 카드에 적용한다. [HTML 시안](card-drawing-toggle-mockup.html)은 이 흐름을 이해하기 위한 모형이며 실제 Obsidian 구현 검증은 아니다.

**미결정:** 카드 전용 그리기를 켰을 때 오른쪽 레이어 패널을 카드별 목록으로 바꿀지, Canvas 레이어와 함께 보여줄지. 이 답에 따라 표시·잠금·불투명도·색 혼합·Undo의 카드별 적용 범위를 연결해 설계한다. 카드 그림과 기존 Canvas 그림이 모두 보인다는 사용자 결정은 이 미결정과 별도로 유지한다.
