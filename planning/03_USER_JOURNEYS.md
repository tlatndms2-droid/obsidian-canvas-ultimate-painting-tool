# 3단계 — Canvas 그림 도구의 사용 흐름 초안

이 문서는 **사용자가 처음부터 끝까지 어떻게 쓰는지**를 정리한다. 버튼의 정확한 모양·위치별 상세 상태와 브러시 내부 설정은 다음 단계에서 설계한다. 기존 자료의 목표, 이후 사용자 결정, CSP 참고 기본값을 혼동하지 않는다. 현재 시험판에서 확인된 결과를 완성된 제품으로 표시하지 않는다.

표시: **결정** = 기존 요구 또는 이후 사용자 답변으로 정한 결과 · **참고** = CSP에서 가져온 기본 흐름 · **미완료** = 세부 기능·UI 또는 제품 검증이 남음.

## A. 처음 열어서 바로 그린다

**시작:** 사용자가 카드가 있는 `작업.canvas`를 연다. 아직 그림 레이어가 없을 수 있다.

1. 왼쪽 그림 도구 막대에서 **브러시**를 고른다. 도구 막대 옆 프리셋 목록에서 붓을 고르고 색·크기를 확인한다.
2. 카드 위 또는 빈 공간을 펜·마우스로 끌어 선을 그린다. 첫 입력이라면 `Layer 1`이 생겨 선택된다. 카드가 끌려가거나 선택되지는 않는다.
3. `Space+드래그` 또는 휠 클릭+드래그로 화면을 옮기고, 휠로 확대한다. 그림과 카드의 상대 위치는 그대로다.
4. 카드 선택 도구로 바꿔 카드를 끈다. 브러시 선은 남아 있고 카드 조작으로 돌아간다.

**끝:** 그림은 현재 Canvas의 그림 레이어에 남고 카드보다 앞에 보인다. **상태:** 핵심 동작 결정, 작은 Sandbox 화면에서 일부 확인. 최종 UI와 대형 Canvas 성능은 미완료.

## B. 두 레이어로 그리며 색을 섞는다

**시작:** `Layer 1`에 노란 그림이 있다.

1. 오른쪽 레이어 패널에서 새 레이어를 만들고 선택한다. 아래 노란 그림과 위 레이어의 내용은 따로 남는다.
2. 붓 색을 파랑으로 고른다. 색 혼합 설정의 기본 범위는 **현재 레이어만**이다. 이 상태로 그리면 아래 레이어의 노랑은 혼합 재료가 되지 않는다.
3. 사용자가 **보이는 그림 레이어 색 참고**로 바꾼 뒤 같은 위치에 새 선을 그리면, 아래 노랑을 참고한 결과가 위 레이어에 그려진다. 아래 원본 그림은 바뀌지 않는다.
4. 레이어의 표시를 끄거나 다시 켜서 두 내용을 구분해 볼 수 있다. 잠근 레이어에는 그리거나 지울 수 없다.

**끝:** 새 선은 선택한 위 레이어에 남는다. 다음 선에서 기본 붓 색을 유지하는 동작은 CSP 참고값이다. **상태:** 혼합 범위·기본값은 사용자 결정. 실제 색감, 혼합 세부 설정과 각 화면 표시는 미완료.

## C. Photoshop 브러시를 가져와 다른 Canvas에서도 쓴다

**시작:** `작업.canvas`를 열어 브러시 패널을 보고 있다.

1. **가져오기**를 누르고 ABR 파일을 고른다. 지원 가능한 팁·설정이 일반 브러시 프리셋으로 나타난다.
2. 이름과 선 미리보기를 보고 하나를 선택해 Canvas에 그린다. 여러 브러시가 담긴 파일을 출처별 그룹에 놓는 방식은 CSP 참고 기본값이다.
3. `아이디어.canvas`를 열면 같은 Vault의 프리셋 목록에서 이 브러시를 다시 고를 수 있다. 두 Canvas의 그림 내용은 섞이지 않는다.

**끝:** 브러시 목록은 같은 Vault에서 재사용하고, 그린 결과는 각 Canvas에 남는다. **상태:** Vault 공용 프리셋은 사용자 결정. 일부 실제 ABR의 가져오기·그리기·사용자 체감 렉 개선 확인. 모든 ABR 설정의 변환·가져오기 피드백 UI는 미완료.

## D. 색을 가져오고 그림 일부를 지운다

**시작:** 현재 레이어에 선이 있고, Canvas에 카드 또는 이미지가 보인다.

1. **스포이드**를 고른 뒤 카드·이미지·그림 중 보이는 한 지점을 누른다. 얻은 색이 현재 붓 색 표시로 바뀌며 이후 그림에 쓸 수 있다.
2. **지우개**를 고르고 현재 그림 레이어 위를 문지른다. 닿은 부분만 지워진다. 한 획 전체가 없어지는 방식이 아니다.
3. 잠긴 레이어에서는 지워지지 않는다. 필요한 경우 레이어 잠금을 풀고 다시 지운다.

**끝:** 새 색은 다음 그림에 사용되고, 지운 부분만 현재 레이어에서 사라진다. **상태:** 기존 자료의 목표. 시험판의 화면 색 선택 일부를 확인했지만 최종 UI·잠금 피드백·모든 카드 유형은 미완료.

## E. 그림 영역을 선택해 고친다 — 후속 기능 목표

**시작:** 한 레이어에 카드 위로 뻗은 그림이 있다.

1. 왼쪽 도구 막대에서 **사각형 선택** 또는 **올가미 선택**을 고르고 현재 레이어의 그림 일부를 둘러싼다. 카드 선택 도구와 분리된다.
2. 테두리 안을 끌어 이동하거나 모서리 조절점을 끌어 크기를 바꾼다. 선택 작업 막대에서 회전·좌우/상하 반전·삭제를 실행한다.
3. `Ctrl+C` 또는 `Ctrl+X` 후 `Ctrl+V`로 붙여넣으면 현재 레이어에 들어가고 선택된 상태가 된다. 영역 밖을 누르면 선택이 풀린다.

**끝:** 선택 영역의 그림 부분만 바뀌고 카드 자체는 그대로다. **상태:** 선택 시작점·주요 조작은 사용자 결정과 기존 요구. 자세한 선택 표시·변형 완료/취소 상태 및 실제 제품 동작은 미완료.

## F. 도형·문자를 놓고 다시 수정한다 — 후속 기능 목표

**시작:** Canvas에서 그림 레이어를 선택했다.

1. **도형**을 고르고 직선·사각형·원·타원·화살표 중 하나를 만들어 현재 레이어에 놓는다. 도형은 외곽선만 사용한다.
2. 만든 도형을 다시 골라 위치·크기·선 굵기·색을 바꾼다. 직선과 화살표는 양 끝점을 조절한다.
3. **문자**를 고르고 Canvas 위치를 눌러 입력한다. 나중에 내용·위치·글자 크기·색을 바꾼다.

**끝:** 도형·문자가 선택한 그림 레이어에 남고 카드보다 앞에 표시된다. **상태:** 기존 자료의 기능 목표. 화면별 상세 조작과 저장·Undo 과정은 미완료.

## G. 되돌리고 저장한 뒤 다시 연다

**시작:** Canvas에서 그림을 그리고 카드를 옮기는 등 여러 작업을 했다.

1. 그림 작업 내역과 Canvas 카드 작업 내역은 서로 따로 보존한다. `Ctrl+Z`는 현재 도구가 그림 도구이면 그림을, 일반 카드 선택 도구이면 카드 작업을 되돌리는 **B 방식**을 사용한다. `Ctrl+Shift+Z`는 해당 대상의 다시 실행을 맡는다. 단축키가 두 내역을 동시에 바꾸지 않는 실제 제품 검증이 필요하다.
2. Canvas를 닫고 다시 열거나 Obsidian을 재시작한다. 그림과 레이어, 카드와의 위치 관계가 그대로 돌아와야 한다.
3. Canvas를 복제하면 복제본은 자기 그림을 따로 가진다. Canvas 이름을 바꾸거나 이동해도 그림 연결이 유지된다. 플러그인을 껐다 켜도 그림 자료를 보존한다.
4. Obsidian 내부 휴지통 또는 Windows 휴지통에서 Canvas를 복원하면 연결된 그림도 돌아와야 한다.

**끝:** 같은 그림을 다시 볼 수 있고 복제본의 편집은 원본과 독립적이다. **상태:** 결과는 기존 요구·사용자 결정. Sandbox에서 일부 경로는 확인했지만 제품의 데이터 안정성과 모든 전환·복구 경로는 미완료.

## H. 자주 쓰는 붓을 조정하고 다시 찾는다

**시작:** 브러시 패널에 여러 프리셋과 그룹이 있다.

1. 프리셋의 이름·선 미리보기를 보고 하나를 고른다. 현재 선택된 프리셋이 다른 항목과 구분되어 보인다.
2. 브러시 설정을 열어 크기·필압·손떨림 보정 등 해당 프리셋의 값을 조정한다. Canvas에 그려 결과를 본다.
3. 다른 프리셋을 골랐다가 이전 프리셋으로 돌아오면 그 프리셋에 저장된 설정을 다시 사용한다. **이 반복 동작은 CSP식 도구 사용의 참고 흐름**이며, 어떤 값이 즉시 저장되고 무엇을 별도로 저장하는지는 4·5단계에서 정한다.
4. 사용자는 그룹을 만들거나 이름을 바꾸고, 프리셋 순서를 바꾸거나 그룹 사이를 옮겨 목록을 정리한다.

**끝:** 같은 Vault의 다른 Canvas에서도 정리한 프리셋을 선택할 수 있다. **상태:** 프리셋별 설정·그룹 관리와 Vault 공용 범위는 기존 요구 및 사용자 결정. 정확한 저장 피드백과 조작 UI는 미완료.

## I. 레이어를 관리하고 그림을 다시 확인한다

**시작:** Canvas에 그림 레이어가 둘 이상 있다.

1. 오른쪽 레이어 패널에서 현재 레이어를 고른다. 선택된 레이어를 눈에 띄게 표시한다. 그리기·지우개는 이 레이어에 적용된다.
2. 이름을 바꾸고 표시를 끄거나 켜서 내용을 비교한다. 잠그면 그 레이어에 새 그림이나 지우개가 적용되지 않는다.
3. 레이어의 불투명도와 순서를 조절하면 Canvas 위의 겹침 결과가 달라진다. 각 레이어의 그림 내용 자체는 유지된다.
4. 레이어 그룹·합치기는 기존 자료의 전체 기능 목표지만, 앞서 정한 단계 구분에 따라 **후속 버전의 사용 흐름**으로 둔다. 합친 결과와 되돌리기는 후속 기능 설계에서 구체화한다.

**끝:** 다시 Canvas를 열어도 이름·순서·표시·잠금·불투명도와 그림 내용이 돌아와야 한다. **상태:** 기본 결과는 기존 요구. 패널의 세부 조작과 모든 상태 표시는 미완료.

## J. 그리는 동안 카드를 선택하고 그 카드에만 그린다

**시작:** Canvas에 카드 A·B와 카드 위를 지나가는 기존 Canvas 그림이 있다. 사용자는 브러시 또는 다른 그림 도구를 쓰고 있다.

1. 기본 그리기에서는 카드 위와 빈 공간을 이어 그린다. 카드는 선택되거나 이동하지 않고, Canvas 그림은 카드보다 앞에 보인다.
2. 그리기 설정에서 **그리면서 카드 선택**을 켠다. 왼쪽에 새 `그릴 카드` 도구로 바꾸는 것이 아니므로 현재 그림 도구를 계속 쓸 수 있다. 다른 그림 도구를 골라도 이 설정이 유지된다.
3. 카드 A를 클릭한다. A는 **움직이지 않고 선택만** 되며, A 바로 위의 카드 메뉴바가 나타난다. 여기서 계속 Canvas 전체에 그릴 수도 있다.
4. 카드 메뉴바에서 **선택한 카드만 그리기**를 켠다. 이후 그린 선은 A 안에만 들어가고 카드 경계 밖·B에는 그려지지 않는다. 기존 Canvas 그림은 그 아래로 내려가거나 사라지지 않는다.
5. 일반 카드 선택 도구로 바꾸어 A를 이동하면 A 전용 그림은 함께 이동한다. Canvas 전체에 그린 선은 원래 Canvas 위치에 남는다. A 크기를 바꾸면 A 전용 그림도 함께 확대·축소된다.

**결과:** Canvas 전체 그림과 카드 A 전용 그림을 모두 볼 수 있고, A 전용 그림은 A에 귀속된다. 글 내용만 바뀌면 그림은 카드 안의 같은 위치에 남는다. 삭제/삭제 Undo와 복제도 카드와 그림이 함께 처리되며 복제본은 독립이다. 글·이미지·파일 카드에 같은 원칙을 적용한다.

**상태:** 사용자 경험은 최근 대화에서 결정. HTML은 조작 설명용 시안일 뿐 실제 Obsidian 구현 확인은 아니다. 카드 전용 그림에서 오른쪽 레이어 목록이 어떻게 전환되는지는 미결정이다.

## 3단계에서 아직 끝내지 않은 점

- 위 흐름은 주요 작업의 시작·행동·결과를 연결한 **초안**이다. 프리셋 설정의 저장 시점, 선택 변형의 완료/취소, 레이어 삭제 후 선택 상태처럼 화면·상태가 갈리는 부분은 4·5단계에서 구체화해야 한다.
- `Layer 1`부터 그룹·합치기까지의 **전체 기능 목표**와 어느 버전에 넣을지는 다른 문제다. 이전 출시 관련 답변은 기능·UI를 만든 뒤 다시 범위 정리 단계에서 대조한다.
- 색 혼합의 감각, ABR 호환 범위, 대형 Canvas 반응성은 시험판 일부 결과만 있다. 기획 완료나 제품 통과로 간주하지 않는다.
- 휴지통 영구 삭제 후 그림 자료 정리의 세부 정책은 이전 합의대로 보류한다. 이 흐름에서 임의로 정하지 않는다.

다음에는 위 흐름을 기능별 조작·결과·상태로 나눠 4단계 기능 설계로 이어간다. UI의 정확한 화면 배치·버튼·상태는 5단계에서 별도로 완성한다.
