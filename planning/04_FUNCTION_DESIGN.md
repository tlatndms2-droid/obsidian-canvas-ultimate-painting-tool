# 4단계 — 기능별 동작 설계 (작업 초안)

이 문서는 [대표 사용 흐름](03_USER_JOURNEYS.md)을 사용자가 실제로 누르는 기능과 화면 결과로 나눈다. **전체 기획 또는 UI 시안 확정본이 아니다.** `확정`은 사용자가 직접 정한 결과, `기준안`은 기존 자료와 CSP 사용 방식에서 가져온 설계 출발점, `미정`은 아직 선택·시각 설계·실제 구현 검증이 필요한 내용이다. 기술 시험 통과와 제품 기능 완성도는 구분한다.

## 1. 기능 지도와 연결

| 기능 묶음 | 사용자가 하려는 일 | 먼저 필요한 것 | 현재 상태 |
|---|---|---|---|
| 도구 전환·Canvas 조작 | 카드 조작과 그림 그리기를 오가기 | 현재 Canvas와 입력 위치 | 선택 시작 방식 확정, 세부 충돌 처리 기준안 |
| 브러시·프리셋 | 필압과 크기를 조절해 선 긋기 | 그리기 도구·활성 레이어 | 목표와 일부 시험 결과, 상세 설정 미정 |
| 색·혼합 | 그림의 색을 고르고 겹쳐 칠하기 | 브러시·그림 레이어 | 참조 범위 확정, 혼합 결과 기준안 |
| 레이어 | 그림을 나누고 표시·잠금·순서를 바꾸기 | 그림이 있는 Canvas | 주요 목표, 세부 조작 미정 |
| ABR 가져오기 | Photoshop 브러시를 프리셋으로 쓰기 | ABR 파일 | 시험한 샘플 범위 작동, 호환 표시 미정 |
| 지우개·스포이드 | 일부를 지우고 보이는 색을 찍기 | 활성 도구·레이어 | 기존 목표, 샘플링 세부 미정 |
| 실행 취소·저장 | 편집을 되돌리고 다시 열어도 유지하기 | 편집 기록·Canvas 연결 | 요구 결과 확정/목표 혼재, 제품 검증 필요 |
| 영역 선택·변형 | 사각형/올가미 안의 그림을 옮기기 | 선택 도구·활성 레이어 | 선택 시작 확정, 편집 동작 기준안 |
| 도형·문자 | Canvas 위에 형태와 글을 배치하기 | 도구·활성 레이어 | 기존 목표, 편집 UI 미정 |

**기본 관계:** Canvas 카드 자체는 Obsidian의 카드로 남는다. 그림은 Canvas 공간에 놓이고 카드 앞에 보인다. 그림 레이어의 위아래 순서는 바꿀 수 있지만 카드보다 뒤에 놓는 선택은 제공하지 않는다. 그림은 해당 Canvas에 속하고, 같은 Vault의 브러시 프리셋은 다른 Canvas에서도 쓴다.

## 2. 그리기 도구와 Canvas 조작

| 상황 | 사용자가 하는 일 | 화면과 동작의 기준안 | 남는 상태 |
|---|---|---|---|
| 카드 편집 | 왼쪽 도구 막대에서 선택 도구를 누르고 카드를 클릭/드래그 | Obsidian Canvas의 카드 선택·이동을 사용 | 그림은 바뀌지 않음 |
| 그림 시작 | 브러시를 누르고 Canvas에 펜 또는 마우스로 선을 긋기 | 포인터를 따라 즉시 선이 보임. 첫 그림이면 `Layer 1`이 자동 생성됨 | 현재 Canvas의 활성 그림 레이어에 획이 남음 |
| 화면 이동·확대 | Space+드래그, 휠 클릭 드래그, 휠 확대/축소 | 그리기 중에도 화면만 움직이며 그림과 카드의 상대 위치가 유지됨 | 그림 위치 데이터는 바뀌지 않음 |
| 그림 선택 | 사각형 또는 올가미 도구를 고른 뒤 영역을 그리기 | 활성 그림 레이어의 내용에 선택 경계가 나타남 | 선택을 해제해도 그림 자체는 유지 |

도구를 바꾸면 다음 입력부터 새 도구가 작동한다. 카드 위에 그릴 때는 카드가 우발적으로 이동하지 않게 하고, 선택 도구로 돌아오면 카드 조작이 다시 가능해야 한다. 도구별 포인터 모양, 단축키 충돌, 카드 위에서 선택 도구가 그림과 카드를 어떻게 구별하는지는 5단계 화면/상태 설계에서 구체화한다.

## 3. 브러시와 프리셋

**예시:** 프리셋 목록에서 수채 브러시를 누름 → 크기를 30으로 바꿈 → 화면에 선을 그림 → 같은 프리셋을 다시 고르면 마지막 설정이 어떻게 적용되는지 화면에서 알 수 있어야 한다.

| 항목 | 화면에서 해야 할 일 | 동작 기준안 | 구분 |
|---|---|---|---|
| 프리셋 선택 | 브러시 목록에서 이름·미리보기를 눌러 선택 | 선택한 브러시의 현재 설정이 도구 막대와 설정 화면에 반영 | 기준안 |
| 크기·불투명도 | 슬라이더 또는 숫자 입력으로 변경 | 다음 선부터 반영하며 그리는 중 결과를 볼 수 있음 | 기존 목표 |
| 필압 | 연결된 펜으로 힘을 달리해 그리기 | 해당 프리셋에서 필압을 켠 속성만 크기/불투명도 등에 반영 | 목표; 실제 필압 입력은 시험했으나 전체 프리셋 품질 미확정 |
| 안정화·질감 | 브러시 설정에서 조절 | 프리셋별로 필감을 바꾸며 선의 모양과 반응성이 함께 평가 대상 | 기준안 |
| 프리셋 저장 | 조절 후 저장 또는 복제 | 원본 덮어쓰기와 새 프리셋 만들기의 결과가 구분되어야 함 | 세부 UI·기본값 미정 |

기존 자료의 브러시 설정 9개 범주(기본 크기·불투명도, 브러시 팁, 스트로크/간격, 필압·입력 변화, 질감, 색 변화, 혼합, 안정화/보정, 프리셋 관리)는 **설계 범위 후보**다. 범주 안의 모든 CSP 옵션을 동일하게 제공한다는 뜻은 아니다. 설정별 표시 조건·저장 단위·초기값은 실제 UI 설계에서 정리한다. 프리셋은 같은 Vault의 Canvas에서 재사용하고, 이미 그린 획의 모양이 프리셋 변경 때문에 예기치 않게 바뀌어서는 안 된다.

## 4. 색 선택과 색 혼합

**예시:** 파란 선이 있는 `Layer 1` 위에 붉은 브러시로 칠한다. `현재 레이어`를 고르면 현재 레이어의 색을 참고하고, `보이는 그림 레이어`를 고르면 화면에 켜진 그림 레이어의 색도 참고한다. 어느 경우에도 아래 레이어의 원본 색을 직접 바꾸지는 않는다.

| 조작 | 화면 결과 | 저장/상태 |
|---|---|---|
| 색상 선택 | 색상 선택기에 현재 색이 표시되고 이후 선에 적용 | 현재 브러시 색 유지 |
| 혼합 끄기 | 새 선이 설정된 색·불투명도로 그려짐 | 기존 선 유지 |
| 혼합 켜기 | 선이 지나가는 기존 그림 색을 참고해 칠해지는 모습이 보임 | 결과는 그린 레이어에 저장 |
| 참조 범위 전환 | `현재 레이어` 또는 `보이는 그림 레이어`를 선택 | 기본은 `현재 레이어`; 숨긴 레이어는 전체 참조에서 제외 |

카드/이미지의 화면 색까지 혼합 대상으로 삼는 것은 확정하지 않았다. 색이 섞이는 시각적 규칙, 브러시별 혼합 강도, 선을 그리는 도중 설정 변경 허용 여부도 미정이다. 사용자가 원하는 것은 CSP에 가까운 **눈에 보이는 채색 경험**이므로 알고리즘 이름보다 예시 그림과 실제 필감으로 평가한다.

## 5. 레이어

**예시:** 카드 위 밑줄을 `Layer 1`에, 장식 선을 `Layer 2`에 그림 → `Layer 2`를 끄면 장식만 숨음 → 다시 켜면 나타남 → 잠그면 장식은 지워지거나 새로 그려지지 않음.

| 조작 | 사용자가 보는 결과 | 보존되어야 하는 것 | 상태 |
|---|---|---|---|
| 첫 그리기 | `Layer 1` 자동 생성, 활성 표시 | 첫 획이 그 레이어에 남음 | 기존 기준 |
| 새 레이어 | 목록에 새 행이 생겨 활성화 | 기존 레이어의 그림 유지 | 기준안 |
| 선택·이름 변경 | 선택 강조·새 이름 표시 | 다른 레이어 그림 유지 | 기준안 |
| 눈 아이콘 | 해당 레이어의 그림만 숨김/표시 | 숨겨도 내용은 삭제되지 않음 | 기존 목표 |
| 잠금 | 잠긴 레이어에서 그리기·지우기·이동을 막고 잠금 표시 | 내용 유지 | 기존 목표 |
| 불투명도 | 레이어 전체가 옅거나 진하게 보임 | 개별 획의 원래 설정 유지 | 기존 목표 |
| 순서 변경 | 그림 레이어끼리 앞뒤가 바뀜 | 카드보다 그림이 항상 앞에 보임 | 사용자 확정 |
| 삭제·합치기 | 대상과 되돌릴 수 있는 결과를 미리 알 수 있어야 함 | 실행 취소 가능해야 함 | 목표, 정확한 UI·범위 미정 |

레이어 그룹, 합치기, 혼합 모드, 실제 내용 미리보기는 기존 자료의 목표다. 예전의 “후속 버전” 답변은 범위를 검토할 때의 참고일 뿐, 지금 전체 기능에서 제외 확정한 것은 아니다. 그룹 안 순서, 합치기 뒤 이름/불투명도, 비어 있는 마지막 레이어를 삭제할 때의 상태는 5–6단계에서 정한다.

## 6. Photoshop 브러시 가져오기

**예시:** ABR 파일 선택 → 브러시 목록과 미리보기 확인 → 필요한 항목을 가져옴 → 프리셋 목록에서 선택해 그림 → 같은 Vault의 다른 Canvas에서도 해당 프리셋을 찾음.

| 시점 | 동작·표시 기준안 |
|---|---|
| 파일 선택 | ABR 파일을 선택하고 읽을 수 있는 브러시를 목록으로 제시 |
| 가져오기 전 | 이름·미리보기·지원되지 않는 속성의 영향을 알 수 있게 표시. 빈 항목과 중복 이름은 구별 |
| 가져오기 후 | 일반 브러시와 같이 고르고 설정을 바꿔 쓸 수 있음. 해당 Vault의 다른 Canvas에서도 사용 가능 |
| 문제가 있는 항목 | 전체 파일이 조용히 성공한 것처럼 보이지 않게 해당 항목 결과를 표시 |

일부 ABR 샘플이 Obsidian Sandbox에서 그려지고 성능 문제가 개선된 것은 **그 샘플의 시험 결과**다. Photoshop의 모든 버전/모든 속성/원본과 동일한 획 품질을 검증한 뜻은 아니다. 지원 속성 표와 미지원 표시 문구는 실제 파일 사례를 기반으로 후속 설계한다.

## 7. 지우개·스포이드·되돌리기

| 도구 | 사용자가 하는 일 | 결과 기준안 | 남은 설계 |
|---|---|---|---|
| 지우개 | 지우개를 고르고 그림 위를 문지름 | 활성·잠금 해제 레이어에서 닿은 부분만 지워짐; 다른 레이어·카드는 유지 | 크기·필압·지우기 감도 |
| 스포이드 | 스포이드를 고르고 화면의 보이는 색을 클릭 | 찍힌 색이 현재 색에 나타나고 다음 브러시 선에 사용 | 카드·이미지·투명/혼합 픽셀의 샘플 규칙 |
| 실행 취소 | 그림 도구에서 Ctrl+Z 또는 그림 Undo를 누르기 | 별도 그림 내역의 직전 편집 1건만 되돌림. 일반 카드 선택 도구에서는 Canvas 카드 내역을 되돌림 | B 방식의 충돌 없는 실제 단축키 연결·각 편집의 묶음 단위 검증 필요 |
| 다시 실행 | 현재 도구의 되돌리기를 다시 실행 | 해당 내역에서 취소했던 결과가 재현 | 새 편집 시작 시 재실행 기록 처리 |

선 하나를 그리는 동안의 무수한 입력점을 각각 Undo 1회로 만들지 않는다. 레이어 삭제/합치기 역시 복구 가능한 편집으로 취급해야 한다. 전체 화면에서 색을 찍는 목표는 있으나 모든 Obsidian 화면 상태에서 정확히 되는지는 별도 제품 검증 대상이다.

## 8. 저장·Canvas 수명 주기

그림을 그리면 화면에는 즉시 반영하고, 저장은 변경을 모아 자동으로 진행한다. 사용자는 저장 버튼을 매 획마다 누르지 않는다. 그림 데이터는 Canvas 파일과 연결되어 보존하며, 플러그인을 끄거나 제거해도 지우지 않는다.

| 상황 | 사용자가 기대하는 결과 | 분류 |
|---|---|---|
| Canvas를 닫고 다시 열기/Obsidian 재시작 | 카드와 그림의 위치·레이어·색·표시 상태 복원 | 제품 목표, 개별 시험과 전체 제품 검증 구분 |
| Canvas 이름 변경·폴더 이동 | 연결이 끊기지 않고 같은 그림 표시 | 기존 요구 |
| Canvas 복제 | 원본과 복제본이 처음에는 같고 이후 편집은 서로 독립 | 기존 요구 |
| 플러그인 끄기/제거 후 다시 사용 | 보존한 그림이 다시 나타남 | 사용자 확정 |
| Obsidian 내부 `.trash` 또는 Windows 휴지통에서 복원 | 그림도 함께 복원 | 사용자 확정, 시험 범위 기록 필요 |
| 영구 삭제 | 더 이상 필요 없는 연결 데이터의 정리 시점·방법 필요 | 미정 |

저장 중 앱이 닫히거나 동기화가 충돌할 때의 복구 표시는 6단계 예외 설계로 넘긴다. 그림 파일 형식·식별자·저장 간격은 사용자가 보는 결과를 만족하도록 구현 단계에서 정하며 여기서 임의 확정하지 않는다.

## 9. 영역 편집·도형·문자 — 계속 설계할 기능

사각형/올가미 선택을 **왼쪽 도구 막대에서 시작**한다는 점은 확정이다. 기준안은 현재 활성 레이어에서 영역을 고른 뒤 이동·크기 변경·복사·삭제하고, 확정 전 미리보기와 취소 경로를 제공하는 것이다. 빈 영역, 여러 레이어 동시 선택, 카드와 겹친 선택의 화면 반응은 미정이다.

도형은 도구 선택 → Canvas에서 위치와 크기 지정 → 활성 그림 레이어에 표시되는 흐름, 문자는 도구 선택 → 위치 클릭 → 글 입력/편집 → 배치되는 흐름을 기본 후보로 둔다. Shape Fill은 기존 자료의 기본 제외 항목이다. 도형/문자의 재편집 방식, 글꼴·정렬·속성 패널, 그림과 같은 선택 도구를 공유할지는 5단계 UI 설계에서 비교한다.

## 10. 기능 간 상태 변화와 다음 설계 경계

| 상태 변화 | 바로 바뀌는 화면 | 그대로 남아야 하는 것 |
|---|---|---|
| 선택 도구 → 브러시 | 브러시 활성 표시, 다음 드래그가 선으로 보임 | 카드 위치 |
| 브러시 → 지우개 | 지우개 활성 표시, 다음 드래그에서 활성 레이어 일부가 지워짐 | 다른 레이어·카드 |
| 레이어 표시 끔 → 켬 | 해당 그림만 사라졌다 돌아옴 | 저장된 그림 내용 |
| 현재 레이어 혼합 → 보이는 레이어 혼합 | 새 선의 색 참조 범위 변경 | 기존 획과 하위 레이어 원본 |
| Canvas A → Canvas B | B의 그림과 상태가 로드되고 Vault 프리셋은 공통으로 사용 | A의 그림·편집 내용 |
| 플러그인 끔 → 다시 켬 | 그림이 숨었다 다시 표시됨 | 그림 데이터 |

**이 단계에서 아직 확정하지 않은 중요한 결과:** 프리셋 설정을 언제 원본에 덮어쓸지, 레이어 삭제/합치기의 정확한 사용자 확인과 Undo 단위, 영역 변형 확정·취소, 지원되지 않는 ABR 속성의 표시, 스포이드가 카드/이미지의 어떤 색을 찍을지, 저장 실패 시 복구 안내. 이들은 화면에 보이는 결과가 달라지는 내용이므로 5단계 UI·상태 설계에서 실제 예시와 함께 결정한다. 일반적인 작은 조작은 CSP 관례를 기준안으로 삼고 모두 질문하지 않는다.

## 11. 카드 선택 가능한 그리기와 카드 전용 그림 — 후속 기능 설계

| 상태/기능 | 사용자가 하는 일 | 화면 결과 | 그림이 속하는 곳 |
|---|---|---|---|
| 기본 그리기 | 카드 위·빈 공간에 그린다 | 카드가 선택·이동되지 않고 선은 카드 앞에 보인다 | 현재 Canvas의 그림 |
| 그리면서 카드 선택 | 그리기 설정을 켜고 카드를 클릭한다 | 그림 도구는 유지되고, 클릭한 카드는 이동 없이 선택되며 카드 위 메뉴가 나타난다 | 새 선은 카드 메뉴의 토글을 켜기 전까지 Canvas 그림 |
| 도구 전환 | 브러시에서 다른 그림 도구로 바꾼다 | `그리면서 카드 선택` 상태가 유지된다 | 도구와 선택 가능 상태는 독립 |
| 선택한 카드만 그리기 | 선택된 카드 위 메뉴의 토글을 켜고 카드 안에 그린다 | 그 카드 안에만 선이 나타난다. 기존 Canvas 그림은 그대로 앞에 보인다 | 선택한 카드 전용 그림 |
| 기존 카드 선택 | 왼쪽 일반 카드 선택 도구로 카드를 끈다 | 카드가 이동하며 카드 전용 그림이 따라간다. Canvas 그림은 원래 좌표에 남는다 | 각 원래 소유 대상 유지 |

카드 전용 그림은 카드 크기 변경 때 함께 확대·축소되며 글 내용 변경만으로 글자를 따라가지는 않는다. 카드 삭제와 삭제 Undo, 카드 복제, 같은 파일의 복수 카드 배치는 각각의 카드 그림을 함께 처리하되 복제본·서로 다른 카드의 그림은 독립이다. 글·이미지·파일 카드를 대상으로 한다. **오른쪽 레이어 패널에 카드 전용 레이어만 표시할지**와 Canvas 그림 레이어와의 관계는 아직 사용자 결정이 없다. 카드 전용 기능이 첫 사용 버전에 포함되는지도 범위 단계에서 재대조한다.

**현재 판정:** 4단계의 기능별 동작 초안을 만들었다. 버튼 배치·패널 상태·빈 화면·경고·단축키·각 기능의 완료 조건을 설계한 뒤 4–5단계를 함께 재검토해야 한다. 이 문서만으로 전체 기획 완료나 전 기능 구현 가능 확정을 말하지 않는다.
