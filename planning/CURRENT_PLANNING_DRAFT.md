## 1. 프로젝트 개요

**한 줄 정의:** 사용자가 Obsidian Canvas의 카드·이미지와 같은 공간에서 그림을 그리고 수정하면서, Canvas의 기존 탐색·카드 조작과 그림 자료를 함께 보존할 수 있게 하는 개인용 데스크톱 플러그인.

Canvas 자체가 그림 공간이다. 별도 그림판 화면을 열거나 한 획을 Canvas 카드 하나로 만들지 않는다. 단순 주석보다 실제 그림 작업을 목표로 하며, Clip Studio Paint(CSP)는 도구 조작의 참고 대상이다. CSP 전체 기능·파일 형식·동일한 색감을 복제한다는 약속은 아니다. **[확정]**

## 2. 해결할 문제와 개발 목적

기존 Canvas의 카드·이미지를 보면서 같은 위치에 자유로운 그림을 얹고, 필요할 때는 특정 카드 자체에 그림을 붙여 이동·복제와 함께 다루고 싶다. 이를 위해 **Canvas 전체 그림**과 **카드 전용 그림**을 구분하면서도 둘 다 한 화면에서 볼 수 있어야 한다. 그림이 많아져도 Canvas 이동·확대·카드 조작이 눈에 띄게 느려져서는 안 된다. **[확정된 목적·성능 기준]**

## 5. 대표 사용 시나리오

### A. Canvas 전체에 그리기

`Canvas 열기 → 왼쪽 브러시 선택 → 프리셋·색·크기 확인 → 카드 위에서 빈 공간까지 선 긋기 → Canvas 이동·확대 → 다시 열기`.
첫 선에서 레이어가 없으면 `Layer 1`을 만들고 선택한다. 그리는 동안 카드는 선택·이동되지 않는다. 선은 카드 앞에 보이며, 카드가 나중에 움직여도 Canvas 전체 그림은 원래 Canvas 위치에 남는다. Space+왼쪽 드래그·휠 클릭 드래그는 화면 이동, 휠은 확대·축소다. Space를 놓으면 쓰던 그림 도구를 계속 쓴다. **[확정]**

### B. 그리는 중 카드를 선택해 그 카드에만 그리기

`브러시 등 그림 도구 사용 → 그리기 설정의 ‘그리면서 카드 선택’ 켜기 → 카드 A 클릭 → A는 이동 없이 선택, A 바로 위 메뉴 표시 → ‘선택한 카드만 그리기’ 켜기 → A 안에 그리기`.
카드 선택 가능 상태에서도 그림 도구를 계속 쓰고, 다른 그림 도구로 바꿔도 그 상태가 유지된다. 메뉴의 카드 전용 토글을 켜기 전까지 새 선은 Canvas 전체 그림이다. 켠 뒤에는 카드 A 안에만 그려지고 카드 경계 밖·다른 카드에는 그려지지 않는다. Canvas에 이미 그린 그림은 계속 카드 앞에 보이며, 새 그림을 그릴 때도 모두 보인다. 일반 카드 선택 도구로 이동할 때 A 전용 그림만 A를 따라간다. **[최신 사용자 확정]**

### C. 레이어와 색 혼합

`현재 레이어에서 색 선택·그리기 → 새 레이어 추가 → 아래 그림을 보며 새 선 그리기 → 혼합 참조를 필요할 때 ‘보이는 그림 레이어’로 변경`.
기본 색 혼합 참조는 **현재 레이어만**이다. 아래 레이어의 색을 참고하더라도 결과는 현재 레이어에 그려지고 아래 그림 자체는 변하지 않는다. 표시/숨김·잠금·불투명도·순서 변경으로 두 그림을 구분해 확인한다. **[혼합 범위 사용자 확정, 실제 색감 목표]**

### D. 브러시를 가져오고 다시 쓰기

`ABR 파일 선택 → 지원 가능한 브러시를 프리셋으로 가져오기 → 선 미리보기·이름을 보고 선택 → Canvas에 그림 → 같은 Vault의 다른 Canvas에서 다시 선택`.
프리셋은 Vault 공용이지만 그림 결과는 Canvas별로 독립이다. 브러시 크기 등 마지막 조절값은 Obsidian을 다시 열어도 유지한다. `기본값으로 저장`은 현재 조절값 유지와 다른 동작이다. **[사용자 확정, ABR 호환 범위 미정]**

### E. 그림·카드를 되돌리고 복원하기

`그림 작업 → 일반 카드 선택 도구로 카드 이동 → 현재 도구에 맞게 Ctrl+Z → Canvas 닫기·재열기 또는 휴지통 복원`.
카드 작업 기록과 그림 작업 기록은 별도다. 그림 도구에서의 Ctrl+Z는 그림 내역, 일반 카드 선택 도구에서의 Ctrl+Z는 카드 내역을 대상으로 하는 **B 방식**을 사용한다. 삭제한 카드의 그림은 카드 삭제 Undo와 함께 돌아와야 한다. Canvas 자체를 두 휴지통 중 하나에서 복원해도 그림이 돌아와야 한다. **[사용자 확정, 단축키 제품 검증 필요]**

## 7. 기능별 동작

### 브러시·설정

브러시 크기는 슬라이더·숫자 입력·`Ctrl+Alt+좌우 드래그`로 조절하며 실제 크기를 커서에서 확인한다. 크기 필압·불투명도 필압은 각각 켜기/끄기와 영향 강도를 갖고, 손떨림 보정은 프리셋별로 저장한다. 설정의 큰 범주는 **Brush Size, Ink, Color Mixing, Brush Tip, Stroke, Stabilization, Texture, Spray/Scatter, Dynamics**의 9가지다. 최소 크기와 필압 곡선도 설정 골격에 포함한다. 범주 안 모든 CSP 항목의 지원을 확정한 것은 아니다. 브러시 커서는 가능한 범위에서 크기·둥글기·각도·팁 모양을 보여준다. **[원본 기준]**

프리셋 패널에는 그룹 생성·삭제·이름 변경·접기/펼치기, 브러시 추가·삭제, 프리셋 순서와 그룹 간 이동, 이름·선 미리보기·현재 선택 표시를 둔다. 가져온 ABR도 같은 목록에서 고른다. 마지막 조절값과 현재 색은 같은 Vault의 다른 Canvas에서도 이어 쓴다. **[원본 기준·사용자 후속 결정]**

### 색·지우개·스포이드

색상환과 스포이드를 둔다. 스포이드는 그림뿐 아니라 카드·이미지를 포함한 화면 결과의 색을 가져오는 목표다. 색 혼합은 단순 불투명도 쌓기보다 페인팅 같은 상호작용을 목표로 하지만 최종 알고리즘·결과 품질을 정하지 않았다. 혼합을 켜고 끄는 조작과 물감 양·농도·색 끌기 같은 세부 값은 목표·후보로 남는다. 지우개는 현재 잠금 해제 레이어에서 **닿은 부분만** 지우며 획 전체 삭제 도구로 쓰지 않는다. **[원본 기준·혼합 참조 범위는 사용자 확정]**

### 그림 영역 선택·도형·문자·클립보드

그림은 획 하나씩이 아니라 **현재 레이어의 영역**을 사각형·올가미로 선택한다. 선택 직후 테두리·조절점을 보여주고 안쪽 드래그로 이동, 모서리 드래그로 크기 변경한다. 작업 막대에서 회전·좌우/상하 반전·삭제를 실행하고, 영역 밖을 누르면 선택이 풀린다. `Delete`는 선택된 그림 부분만 지운다. `Ctrl+C/X/V`의 붙여넣기는 현재 레이어로 들어와 바로 선택된다. 별도 그림 복제 명령은 두지 않는다. **[원본 기준·선택 조작 사용자 확정]**

도형은 직선·사각형·원·타원·직선 화살표의 **외곽선만** 만든다. 이후 위치·크기·선 굵기·색을 바꾸고 직선·화살표 끝점을 다시 조절한다. 문자는 Canvas 위치에서 만들고 나중에 내용·위치·크기·색을 수정한다. 둘 다 현재 그림 레이어에 속한다. **[원본 기준, 세부 UI는 미완료]**

### 그림 레이어

첫 그림에서 `Layer 1`을 만들며, 기본 조작은 추가·삭제·이름 변경·선택·순서 변경·표시/숨김·잠금·불투명도 0~100%다. 실제 그림 축소 미리보기가 목표다. 위의 그림 레이어가 앞에 보이며, 브러시·지우개는 현재 레이어에만 작동한다. 레이어 삭제·합치기는 Undo 가능해야 한다. 레이어 그룹·그룹 표시·접기·합치기·혼합 모드는 전체 기능 목표지만 **그룹·합치기는 후속 버전**이다. 레이어 복제는 제외한다. **[원본 기준·버전 분류 사용자 결정]**

## 8. UI와 사용자 조작

```text
Obsidian의 현재 Canvas
┌─────────┬──────────────────┬────────────────────┬──────────────┐
│ 왼쪽    │ 도구 설정·        │ 카드·이미지·그림이 │ 오른쪽 그림  │
│ 세로    │ 브러시 프리셋     │ 함께 보이는 Canvas │ 레이어 패널  │
│ 도구    │                  │                    │              │
└─────────┴──────────────────┴────────────────────┴──────────────┘
```

왼쪽 일반 카드 선택 도구는 카드를 움직인다. 그림 영역의 사각형·올가미 선택은 별도 그림 도구다. 카드 선택 도구로 바꾸어도 브러시 패널은 화면에 남긴다. **[사용자 결정]**

`그리면서 카드 선택`은 왼쪽에 새 독립 도구를 넣는 방식이 아니라 **그리기 상태 안의 선택 가능 설정**이다. 카드를 클릭하면 카드 바로 위에 원래 카드 메뉴처럼 가로 메뉴가 나오고, 거기에 `선택한 카드만 그리기`를 둔다. 이 토글을 켜도 기존 Canvas 그림의 표시 순서는 아래로 바뀌지 않는다. [카드 동작 HTML 시안](card-drawing-toggle-mockup.html)은 배치·순서 설명용이며 아이콘·색·정확한 크기의 최종 승인본은 아니다. **[최신 사용자 결정]**

`Ctrl+Z`와 `Ctrl+Shift+Z`는 현재 도구의 해당 내역을 되돌리고 다시 실행해야 한다. 전역 그림 도구와 일반 카드 선택 도구 사이에서 어떤 기록을 다루는지 화면·단축키가 모순되지 않아야 한다. **[B 방식 사용자 결정, 실제 연결 검증 필요]**

## 9. 데이터·상태·저장

| 사용자가 보는 자료 | 소유·공유 관계 | 유지·변경 결과 |
|---|---|---|
| Canvas 전체 그림과 그 레이어 | 해당 `.canvas`에 연결된 그림 자료 | 카드가 움직여도 Canvas 좌표에 남음. Canvas 복제 시 그림도 독립 복제 |
| 카드 전용 그림 | **배치된 카드 각각**에 속함 | 카드 이동·크기 변경을 따름. 같은 파일의 두 카드 사이에도 공유되지 않음 |
| 프리셋·그룹·가져온 ABR | 같은 Vault에서 공동 사용 | 다른 Canvas에서도 다시 고름 |
| 마지막 브러시 조절값·현재 색 | 같은 Vault의 그림 작업 상태 | Canvas 전환 뒤 같은 색을 이어 쓰고, 브러시 조절값은 Obsidian 재시작 후 유지 |
| Canvas 카드·이미지·연결선 | Obsidian Canvas의 원래 내용 | 그림 도구가 의도치 않게 이를 선택·이동·증식시키지 않음 |

그림은 입력 중 화면에 바로 보이고 변경사항을 모아 **자동 저장**한다. 포인터가 움직일 때마다 디스크에 쓰지 않는다. Canvas 전환·닫기·Obsidian 종료 때 남은 변경을 보존한다. 많은 그림을 `.canvas`의 카드 항목으로 쌓지 않고 Canvas와 연결된 별도 그림 자료로 다룬다. **정확한 저장 형식·경로·식별 기술은 미확정**이다.

카드 전용 그림은 카드 안에서만 보인다. 카드가 이동하면 같이 움직이고 크기를 바꾸면 같이 확대·축소한다. 카드 텍스트 내용만 바뀌면 그림은 글자가 아니라 카드 안의 위치에 남는다. 카드 삭제/삭제 Undo는 그림도 함께 처리한다. 카드 복제는 그림도 복제하되 원본·복제본 편집은 독립이다. 글·이미지·파일 카드에 적용한다. **[사용자 확정]**

Canvas 이름 변경·폴더 이동은 그림 연결을 유지한다. Canvas 복제본은 독립 그림을 가진다. 플러그인을 끄거나 제거해도 그림 **데이터를 지우지 않고**, 다시 켜거나 설치하면 그림을 표시한다. Obsidian 내부 `.trash`와 Windows 시스템 휴지통에서 Canvas를 복원하면 그림도 돌아온다. 따라서 원본 기획의 `Canvas 삭제 즉시 그림 자료 삭제` 문구는 복원 가능한 삭제에는 적용하지 않는다. **영구 삭제 후 정리 시점·방법은 보류**한다.

## 10. 기능·데이터 간 중요한 관계

| 출발 동작 | 영향받는 결과 | 관계 상태 |
|---|---|---|
| 일반 카드 선택으로 카드 이동 | 카드 전용 그림은 함께 이동; Canvas 전체 그림은 제자리 | 확정 |
| 카드 크기 변경 | 카드 전용 그림도 함께 확대·축소 | 확정 |
| 카드 텍스트만 변경 | 그림은 글자 위치가 아닌 카드 안 위치를 유지 | 확정 |
| 카드 복제 | 카드 전용 그림도 복제, 이후 서로 독립 | 확정 |
| 같은 파일을 두 카드로 배치 | 각 카드의 그림은 서로 독립 | 확정 |
| Canvas 복제 | Canvas 전체 그림도 독립 복제 | 원본 기준 |
| 카드 전용 그리기 켜기 | 오른쪽 레이어 목록과 색 혼합·잠금 적용 범위에 영향 | **재검토 필요** |
| 복원 가능한 Canvas 삭제 | 두 휴지통 복원을 위해 그림 보존 | 후속 결정이 원본 즉시 삭제 규칙을 대체 |

## 11. 예외·실패·복구

- **확정:** 카드 삭제를 Undo하면 카드 전용 그림도 복원한다. Canvas를 두 종류의 휴지통에서 복원하면 연결된 그림도 복원한다. 플러그인을 끄거나 제거한 뒤 다시 켜도 그림 자료는 남아 있어야 한다.
- **보류:** Windows 휴지통을 비워 Canvas가 영구 삭제됐을 때 연결된 그림을 어떤 시점에 안전하게 정리할지. 수동 정리나 기간 경과 자동 삭제를 사용자 승인 없이 추가하지 않는다.
- **검토 필요:** 저장 도중 종료·저장 실패·동기화 충돌 시 화면 안내와 복구. Sandbox 시험 과정의 데이터 손실 사고는 제품에서 같은 오류가 필연적으로 발생한다는 증거가 아니며, 임의의 별도 오류 화면을 확정하는 근거로 쓰지 않는다.

## 12. 제약·성능·호환성

성능은 **P0**다. Canvas Pan·Zoom·카드 선택/이동·다중 선택·그룹 이동·저장·큰 Canvas 탐색을 눈에 띄게 방해하지 않아야 한다. 수천·수만 획의 원본 데이터를 유지하면서 화면 밖·숨김 레이어의 불필요한 표시 작업을 줄이고, 축소 화면에서 간단히 보여주더라도 확대 시 원래 그림 품질을 복원해야 한다. 구체적인 렌더링·캐시·GPU 기술은 기획에서 고정하지 않는다.

Windows 데스크톱을 먼저 다룬다. 실제 필압·기울기 지원, 모든 ABR 속성, 모든 혼합 모드, CSP에 가까운 색감, 큰 Canvas 장시간 반응성은 각각 별도 검증 범위를 가진다. 시험한 일부 ABR에 대해 사용자가 렉 해소를 확인했지만, 이를 전체 브러시·작업량의 성능 통과로 확대하지 않는다. 작은 Sandbox에서는 기본 그리기·Pan/Zoom·저장·재시작·두 휴지통 복원의 가능성을 확인했으나 전체 Canvas 연동 판정은 **부분 통과**다. 자세한 범위는 [POC_RESULTS.md](POC_RESULTS.md)를 따른다.

## 13. 개발 범위와 순서

| 분류 | 기능 | 결정의 의미 |
|---|---|---|
| 첫 사용 버전 우선 안정화 | Canvas 그리기, 기본 레이어, 저장, 색 혼합, Photoshop 브러시 가져오기 | 사용자 답변으로 정한 **우선 기능군**. 세부 조작·품질·배포 시점 확정 아님 |
| 첫 버전을 실제로 쓰기 위한 동반 기능 | 기본 지우개·색 선택·Undo/Redo·Canvas 이동/확대·데이터 보존 | 핵심 기능을 안전하게 쓰기 위한 기획상 필요 조건 |
| 후속 버전 | 그림 영역 선택·변형·복사/붙여넣기, 도형·문자, 레이어 그룹·합치기 | 전체 기능 목표에서 제거하지 않음 |
| 범위 재대조 | 카드 전용 그리기의 첫 버전 포함 여부, 고급 브러시 값·레이어 혼합/미리보기 세부 범위 | 후속 결정과 의존성을 반영해 7단계에서 확정 |
| 제외 | 별도 그림판, 획당 Canvas Node, 레이어 복제, 별도 그림 복제 명령, 도형 채우기, 획 개별 기본 선택, 플러그인 자체 고아 그림 보관 | 원본에서 명시적으로 제외 |

기획과 기능 검증을 함께 진행하되, 기획을 바꿀 핵심 의문만 짧게 시험하고 확인 항목을 반복하지 않는다. 사이트는 사용자가 명시적으로 요청할 때만 갱신하며 기획 문서는 관련 결정을 모아 반영한다. 기능 구현·실제 UI 검증·배포는 이 문서 작성과 다른 단계다.

## 14. 사용자가 확인할 완료 조건 초안

아래는 **완료 판정 기준 초안**이며 아직 통과 결과가 아니다.

1. 카드가 있는 Canvas에서 기본 브러시로 카드 위부터 빈 공간까지 그리면 선이 앞에 보이고 카드가 선택·이동하지 않는다.
2. 그리기 중 `그리면서 카드 선택`을 켜고 카드를 클릭하면 카드가 이동하지 않고 선택되며 카드 위 메뉴가 나타난다. 다른 그림 도구로 바꿔도 선택 가능 상태가 유지된다.
3. 카드 위 메뉴에서 `선택한 카드만 그리기`를 켜고 선을 그으면 해당 카드 안에만 남으며, 기존 Canvas 그림은 전부 계속 보인다.
4. 그 카드의 위치·크기를 바꾸면 카드 전용 그림이 함께 움직이고 확대·축소된다. Canvas 전체 그림은 원래 Canvas 위치를 유지한다.
5. 카드 삭제를 Undo하거나 그림이 있는 카드를 복제하면 카드 전용 그림이 각각 기대한 결과로 복원·독립 복제된다. 같은 파일의 서로 다른 카드 그림은 섞이지 않는다.
6. 색 혼합의 참조를 현재 레이어/보이는 그림 레이어로 전환해도 하위 레이어의 원본은 바뀌지 않는다.
7. Canvas를 닫고 다시 열거나 Obsidian을 재시작하고, 플러그인을 껐다 다시 켜거나, 두 휴지통에서 Canvas를 복원하면 보존해야 할 그림이 돌아온다.
8. 그림 도구와 일반 카드 선택 도구 각각에서 `Ctrl+Z`를 누르면 해당 내역 **한쪽만** 되돌아간다.
9. 큰 Canvas와 많은 그림을 사용해도 기존 Canvas의 이동·확대·카드 조작 반응을 눈에 띄게 해치지 않는다. 수치 통과 기준은 실제 제품 시험 설계에서 정한다.

## 16. 후속 개발과 제외한 아이디어

후속 개발 기능은 **그림 영역 선택·변형·클립보드, 도형·문자, 레이어 그룹·합치기**다. 현재 범위에서 제외한 방식은 별도 Drawing Canvas/Area, 획마다 Canvas Node, 레이어 복제, 독립 그림 복제 명령, 도형 채우기, 개별 획 기본 선택, 플러그인 자체 고아 그림 보관함이다. macOS·Linux·모바일과 공개 배포는 첫 개인용 Windows 버전의 목표가 아니다. 이들은 기술적으로 불가능하다는 판정이 아니라 현재 순서·범위의 결정이다.

## 17. 현재 판정과 문서 근거

**판정:** 프로젝트 목적과 큰 사용 흐름은 설명할 수 있고, 기본 Canvas 연동의 작은 시험에서는 가능성을 확인했다. 그러나 카드 전용 레이어 관계, B 방식 Undo의 제품 동작, 상세 UI·복구·성능과 첫 버전 범위 대조가 남아 있다. 따라서 **5단계 작업본**이며 6단계 예외·제약, 7단계 범위·완료 기준, 8단계 전체 검증을 통과한 최종 개발 기획서가 아니다.
