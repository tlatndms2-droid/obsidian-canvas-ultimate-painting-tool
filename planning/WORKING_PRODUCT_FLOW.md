# Canvas Drawing Tool Bar — 작업용 사용 흐름

이 문서는 **진행 중인 기획안**이다. 기준은 `briefing/source/`의 기존 요구·목표, `PLANNING_STATE.md`의 후속 사용자 결정, `CSP_REFERENCE_RULES.md`의 참고 기본값 순이다. 문서에서 기능 이름이 등장해도 세부 동작·UI·품질·출시 범위까지 모두 확정됐다는 뜻은 아니다. 시험판에 보인 기능도 완성된 제품 기능으로 간주하지 않는다. 사용자는 첫 버전을 단계적으로 만들기로 했다.

## 1. Canvas에서 그림을 시작한다

| 화면·행동 | 기대 결과 | 근거·상태 |
| --- | --- | --- |
| 사용자가 `작업.canvas`를 연다 | 기존 카드·이미지·그룹과 같은 공간에 그림 도구 막대가 왼쪽에, 브러시 프리셋이 그 오른쪽에, 레이어 목록이 오른쪽에 보인다. 별도 그림판은 열리지 않는다. | 기존 UI 확정 |
| 카드 선택 도구에서 카드를 끈다 | Obsidian의 기존 카드 선택·이동을 사용한다. | 기존 UX·사용자 결정 |
| 브러시를 고르고 카드 위나 빈 공간에 그린다 | 현재 선택한 그림 레이어에 선이 나타난다. 그리는 동안 카드는 선택되거나 이동하지 않는다. 첫 그림이고 레이어가 없으면 `Layer 1`을 만든다. | 기존 UX 확정 |
| Space+드래그 또는 휠 클릭+드래그, 휠 | Canvas를 이동·확대하며 그림은 카드와의 위치 관계를 유지한다. | 기존 UX 확정, 작은 시험에서 확인 |

그림 레이어의 표시는 카드보다 앞에 놓는다. 그림 레이어끼리는 목록의 순서대로 겹친다. 이는 사용자의 후속 결정이다.

## 2. 기존 그림 위에 새 그림을 그린다

1. 레이어 패널에서 새 레이어를 만들고 선택한다. 기존 레이어와 새 레이어의 내용은 각각 남으며 화면에는 함께 보인다.
2. 프리셋과 붓 색을 고른다. 크기는 슬라이더·숫자 입력 또는 확정된 단축 조작으로 바꾼다. 필압의 굵기·불투명도 조절과 프리셋별 손떨림 보정은 기존 요구를 따른다.
3. 색 혼합을 켰을 때 기본은 **현재 레이어의 그림 색만 참고**한다. 사용자가 `보이는 그림 레이어 색 참고`로 바꾸면 아래 그림 레이어의 색도 참고해 현재 레이어에 새 선을 그린다. 참고한 아래 그림 자체는 바뀌지 않는다.
4. 색 혼합은 그려진 자리의 결과를 바꾼다. 다음 선의 기본 붓 색은 사용자가 색 선택이나 스포이드로 바꿀 때까지 유지한다. 이 세부 동작은 [CSP 색 혼합 설명](https://help.clip-studio.com/en-us/manual_en/240_brushes/Blending_tools.htm)과 [그리기 색 선택](https://help.clip-studio.com/en-us/manual_en/240_brushes/Drawing_and_painting.htm)을 따른 참고 기본값이다.

현재 색 혼합의 대상 범위는 사용자 확정이다. 색감·번짐·속도·세부 조절값은 제품 개발에서 확인할 품질 목표이며 시험판의 한 결과로 완료 처리하지 않는다.

## 3. 그림 일부를 고치고 되돌린다 — 영역 편집은 후속 버전 목표

| 사용자 행동 | 화면과 결과 | 상태 |
| --- | --- | --- |
| 왼쪽 사각형/올가미 선택 도구로 현재 레이어의 그림 일부를 둘러싼다 | 선택된 그림에 테두리와 조절점, 선택 작업 막대가 나타난다. Canvas 카드 선택 도구와 구분된다. | 사용자 확정 |
| 선택 영역 안을 끌거나 모서리를 끈다 | 선택한 그림이 이동하거나 크기가 바뀐다. | 사용자 확정 |
| 선택 작업 막대에서 회전·반전·삭제를 누른다 | 현재 레이어의 선택한 그림 부분에만 적용된다. 영역 밖을 누르면 선택 해제된다. | 기존 UX·사용자 확정 |
| 복사·잘라내기·붙여넣기 | 붙여넣은 그림은 현재 레이어에 들어가고 바로 선택 상태가 된다. | 기존 UX 확정 |
| 지우개로 문지르거나 Undo/Redo를 누른다 | 지우개는 닿은 그림 부분만 지우고, 그림 작업은 시간순으로 되돌린다. 잠긴 레이어는 보호한다. | 기존 UX 목표. Canvas 카드 작업과의 통합은 시험판에서 일부 확인, 제품 검증 필요 |

도형은 직선·사각형·원·타원·화살표의 외곽선으로 만들고 나중에 이동·크기·색·선 굵기를 바꾸는 목표가 있다. 문자는 Canvas 위치를 눌러 만들고 나중에 내용·크기·색을 수정하는 목표가 있다. 모두 현재 그림 레이어에 속한다는 방향이며 **첫 사용 버전에는 넣지 않는다.** 각 기능의 세부 설계·검증은 남아 있다.

## 4. 브러시와 레이어를 관리한다

- 브러시 프리셋에는 이름과 선 미리보기를 보여주고, 그룹 생성·이름 변경·접기·순서 변경을 제공한다. 선택한 프리셋이 표시되고 해당 설정을 수정할 수 있다. 기존 요구다.
- ABR을 가져오면 지원 가능한 브러시를 같은 프리셋 패널에서 사용한다. 여러 브러시를 담은 파일을 한 그룹으로 정리하는 것은 [CSP의 ABR 가져오기 흐름](https://help.clip-studio.com/en-us/manual_en/240_brushes/Adding_new_brushes.htm)을 따른 **참고 기본값**이다. 시험판에서는 실제 ABR 가져오기·그리기·재시작과 사용자가 체감한 렉 개선을 확인했다. 모든 Photoshop 설정의 재현은 확인하지 않았다.
- 프리셋은 Canvas마다 다시 가져오지 않고 **같은 Vault의 다른 Canvas에서도 고를 수 있다.** 그림 내용은 각 Canvas에 따로 저장한다. 이는 2026-09-27 사용자 확정이다. 다른 Vault까지 자동으로 공유하거나 동기화하는 범위는 확정하지 않았다.
- 첫 버전의 레이어 패널은 새 레이어 만들기·이름 변경·순서·표시·잠금·불투명도에 집중한다. 기존 자료의 레이어 그룹·합치기 목표는 **후속 버전**으로 둔다. 레이어 혼합 모드·내용 미리보기의 상세 범위와 품질은 계속 기획할 부분이다.

## 5. 저장하고 다시 연다

그림 입력은 즉시 화면에 반영하고 변경을 모아 자동 저장한다. Canvas를 닫거나 Obsidian을 재시작해도 카드와 그림의 상대 위치, 각 그림 레이어, 브러시로 그린 내용이 돌아와야 한다. `.canvas`와 그림 자료는 연결하되 그림 데이터가 Canvas 카드 수를 늘리지 않아야 한다.

Canvas 복제본의 그림은 독립 복사본이 된다. 이름을 바꾸거나 이동해도 연결이 유지된다. 플러그인을 끄거나 제거한 동안에는 그림 데이터를 보존하고, 다시 켜면 같은 그림이 보여야 한다. Obsidian 내부 휴지통과 Windows 휴지통에서 Canvas를 복원하면 그림도 돌아온다. 이들은 기존 요구·후속 사용자 결정이며 데이터 수명주기와 복구는 본 개발의 중요한 확인 조건이다.

## 출시 범위 — 사용자 확정과 작업용 세분화

| 단계 | 사용자가 실제로 할 수 있는 일 | 상태 |
| --- | --- | --- |
| 첫 사용 버전의 중심 | Windows Obsidian Canvas에서 붓으로 그리고, 여러 그림 레이어를 쓰며, 색 혼합 범위를 고르고, ABR 브러시를 가져와 같은 Vault의 다른 Canvas에서도 쓰고, 그림을 저장·다시 연다. | 사용자가 단계적 출시와 이 기능군의 우선 안정화를 확정 |
| 첫 버전에 필요한 기본 조작 | 카드 선택과 그림 그리기 전환, Canvas 이동·확대, 기본 지우개와 색 선택, 포함된 그림·레이어 작업의 Undo/Redo, Canvas 복제·이동·휴지통 복원 때 그림 보존. | 위 중심 기능을 안전하게 사용할 동반 조건으로 분류한 **기획상 판단**. 개별 출시 범위의 사용자 확정으로 과장하지 않음 |
| 후속 버전 | 그림 영역의 사각형·올가미 선택과 변형, 도형·문자, 선택 영역 복사·잘라내기·붙여넣기. | 영역 변형·도형·문자의 후속 단계는 사용자 확정. 클립보드는 영역 선택에 의존하므로 같은 후속 단계로 분류한 기획상 판단 |
| 후속 버전 | 레이어 그룹·합치기. | 2026-09-27 사용자 결정. 세부 사용 흐름은 아직 미설계 |
| 세부 순서 미정 | 브러시 고급 설정과 레이어 혼합 모드·내용 미리보기의 어느 부분을 첫 버전 또는 후속 버전에 넣을지. | 기존 자료의 목표는 유지. 세부 동작·품질·출시 순서는 아직 확정하지 않음 |

첫 버전의 대상은 **사용자 본인**으로 확정됐다. 다른 사람에게 공개 배포하는 준비는 첫 버전의 완료 조건에 넣지 않는다. 개인 설치·업데이트 방법은 구현 계획 단계에서 정한다.

단계적으로 만든다는 결정은 후속 기능을 제품 목표에서 삭제하지 않는다. 첫 사용 버전은 포함 기능과 데이터 보존·체감 성능이 실제 Obsidian에서 확인된 뒤에만 완료로 판단한다.

## 사용자가 확인할 완료 조건 초안

1. `작업.canvas`에서 카드 위에 선을 긋고 화면을 이동·확대한 뒤에도 선은 처음 그린 자리에 남는다. 카드 선택 도구로 바꾸면 카드를 평소처럼 움직일 수 있다.
2. 아래 레이어에 노란색, 위 레이어에 파란색을 그린 뒤 색 혼합의 참고 범위를 바꾸면 위 레이어의 새 선 결과가 달라진다. 아래 레이어의 그림은 그대로 남는다.
3. **후속 버전:** 현재 레이어에서 그림 일부를 올가미로 고르고 이동·크기 조절·회전·반전·삭제한 뒤 Undo/Redo를 누르면 각 결과가 순서대로 되돌아오고 다시 적용된다. 카드 작업과 이어진 작업 순서도 맞아야 한다.
4. ABR을 가져와 프리셋을 선택하면 선 미리보기가 보이고 Canvas에 그릴 수 있다. 가져오지 못한 브러시나 적용되지 않은 속성이 있으면 사용자가 구분할 수 있다.
5. Canvas를 닫았다 다시 열고 Obsidian을 재시작해도 그림·레이어·카드와의 위치가 유지된다. 복제·이름 변경·이동·두 휴지통 복원에서도 앞서 정한 결과가 유지된다.
6. 그림을 오래 그린 Canvas에서도 그리는 중인 선과 Obsidian의 화면 이동·확대·카드 조작이 사용자에게 눈에 띄게 멈추지 않는다. 구체 측정 기준은 실제 작업량을 정해 개발 단계에서 검증한다.

위는 **단계가 섞인 목표·완료 조건 초안**이다. 첫 버전의 완료 조건과 후속 버전의 완료 조건은 출시 범위를 정리하면서 각각 더 구체화해야 한다. 현재 시험판이 위 여섯 항목을 모두 통과했다는 뜻은 아니다.

이 문서는 구현 기술·전체 일정·최종 브러시 설정값을 확정하지 않는다. 최종 개발 기획서가 아니며, 남은 중요한 품질·범위 문제를 점검할 작업 기준이다.
