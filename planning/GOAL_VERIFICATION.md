# 사용 가능한 Sandbox 시험 기능 확인

사용자 목표: 추가 확인 기능을 확정할 수 있는 최소 사용 조건까지 구현·확인하고 사용자가 Sandbox에서 직접 확인할 수 있게 남긴다. 한 시험 방식의 실패를 불가능으로 판단하지 않는다. 모든 기능의 구현 가능성 확인 전에는 목표 완료로 표시하지 않는다.

## 완료 증거가 필요한 항목

사용자 확인: 실제 펜 태블릿/액정 태블릿을 사용할 수 있고, 시험 화면 준비 후 직접 그릴 수 있다고 답했다. 자동 시험 후 실제 펜 입력을 확인할 예정이다.

| 항목 | 최소 사용 결과 | 현재 상태 |
|---|---|---|
| 전체 Canvas 스포이드 | 그림·카드·이미지를 실제 클릭해 색을 얻고 그 색으로 그림 | 0.0.2에서 실제 색 선택 확인. 이미지 #229966, 카드 #eefaf2, 그림은 별도 CDP 화면 픽셀과 일치. 새 색으로 후속 선 검증은 보강 필요 |
| 카드와 그림 Undo | 선→카드 이동→선 후 3단계 Undo·Redo에서 각각 정확히 복구 | 0.0.2 toolbar Undo/Redo 3단계 통과. 내부 Canvas history 연결 사용, 다른 버전 호환·단축키 검사 보강 필요 |
| 색 혼합 | 실제 브러시 드래그로 아래 색이 붓에 반영되고 결과 저장·복원 | 노랑 #fcd200 위 파랑 #002185 입력에서 #3D933E 녹색 선 확인. 재시작 복원 확인. 참조 레이어 선택별 시험 보강 필요 |

| 필압·기울기 | 이벤트 처리 시험과 실물 펜 시험을 분리, 사용자가 시험할 입력 표시 제공 | 미완료 |
| Photoshop 브러시 | 출처·라이선스 기록한 실제 ABR의 지원 속성 변환→프리셋→실제 선 | 3개 실제 ABR 파싱: 148+1+1 팁·설정 읽기. Sandbox에서 148팁 가져오기→배 모양 선→재시작 유지 확인. 기본 설정 변환 소스 작성, 아직 설치·UI 검사 전 |
| 레이어 혼합 | 레이어 UI에서 모드를 바꾸면 예상 결과, 저장·재시작 유지 | 두 레이어 multiply 적용과 재시작 복원 확인. 추가 모드 UI 비교 보강 필요 |
| 대형 그림 | 기존 자료와 비교해 유의미한 지연 판단, 개선 또는 검증된 한계 기록 | 기존 반응 저하, 미완료 |
| 기존 확정 기능 전체 | feature-review.html 21개 묶음의 범위와 대조해 빠진 구현 가능성 근거 확인 | 감사 대기 |
| 사용자 인계 | Sandbox에 시험 버튼·자료·안내 유지, 실제 UI 및 재시작 확인 | 미완료 |

기획 미결정인 혼합 레이어 범위는 실험에서 비교할 수 있게 하며, 한 방식을 임의로 최종 확정하지 않는다. ABR 완전 호환은 기존 기획의 요구가 아니므로 실제 지원/미지원 속성을 공개한다. 실제 장치 입력이 없는 자동 시험을 실물 펜 검증이라고 부르지 않는다.

## 현재 인계 상태

- Sandbox `Pen-Input-Lab.canvas`가 열려 있다. `그리기`, 크기 40, 필압으로 굵기 ON. 사용자가 실제 펜으로 그린 뒤 알려주기로 한 질문이 대기 중이다. 이 화면을 조작·재설치하지 않는다고 안내했다.
- 설치본: `poc/evidence/lab-install.json`의 해시 기준 0.0.2. 마지막 설치 후 재시작 확인은 `lab-restart.json`/PNG에 있으며 그 후 변경은 펜 수치 안내 위치 조정이다.
- 현재 프로젝트 소스 `poc/lab-plugin/lab.js`와 빌드 `main.js`에는 설치본 이후 추가 변경이 있다: ABR 기본 설정 자동 변환, 그림 캐시. 아직 Sandbox에 설치하지 않았다. 설치본과 소스를 동일하다고 가정하지 말 것.
- 새 캐시의 headless 비교는 직접 그리기와 alpha 최대 3/255, premultiplied 색 최대 약 3.92/255 차이가 관찰됨. 현재 `test-cache.cjs`의 엄격한 픽셀 동등 검사는 실패 상태이며, 원인(중간 이미지 합성의 반올림) 검토와 적절한 품질 기준/실제 UI 비교가 남음. Obsidian 성능 개선으로 보고하지 말 것.
- 주요 증거: `poc/evidence/lab-history-eye.json`, `lab-brush.json`, `lab-restart.json`, `abr-samples.json`, `lab-cache.json`. 브러시 시험 파일: `Brush-Lab-1790494633341.canvas`.
- 외부 소스/자료: `poc/THIRD_PARTY.md`, `poc/samples/NOTICE.txt`, `poc/abr-tools/vendor/LICENSE`, 의존 버전은 package-lock.json. 공개 배포 없음.

## 다음 작업

1. 사용자 실제 펜 결과와 `penProof`를 읽고 min/max 변화와 실제 pointerType을 확인. Pen 화면을 바꾸기 전에 사용자 답변을 반영.
2. 미설치 ABR 설정 변환을 15px/30도/60%/간격40%인 Photoshop probe로 검사. 고급 Dynamics 자동 변환 미지원과 불가능을 혼동하지 말 것.
3. 캐시 품질 문제를 해결/판정하고 Sandbox 성능 비교. 기존 전체 통과 기준을 임의로 낮추지 말 것.
4. 색 혼합 참조 레이어, 레이어 모드, 브러시 설정, Undo 단축키, 실제 스포이드 선택색으로 그리기를 보강하고 21개 기능 묶음 감사.
5. 최종 설치본 재시작·사용자 안내 확인 전에는 목표 완료로 표시하지 말 것.
