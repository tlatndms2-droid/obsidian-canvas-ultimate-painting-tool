현재 위치

3단계: 실제 사용 순서를 만드는 중

Obsidian Canvas에서 직접 그린다는 방향과 주요 기능 목표는 있습니다. 지금은 Canvas 열기 → 도구 선택 → 그리기·수정 → 저장·다시 열기를 기능별로 끊김 없이 설명하는 단계입니다.

기획 전체가 끝난 상태가 아닙니다.

기능 목록과 HTML UI 모형은 출발 자료입니다. 브러시·색 혼합·레이어·선택 도구의 세부 조작, 화면 상태, 데이터 관계를 아직 정리해야 합니다. 앞서 나온 개인용·단계적 출시 답변은 나중에 범위를 정할 때 다시 확인할 참고 기록으로 둡니다.

이미 확보한 것

기존 기획 자료, 사용자 결정, Windows Sandbox의 일부 구현 가능성 근거.

지금 하는 것

주요 사용 상황마다 시작점·누르는 순서·보이는 결과·저장 후 상태를 연결.

아직 아닌 것

완성된 기능 설계, 최종 UI, 개발 착수 승인, 설치·배포 계획.

단계별 작업과 완료 기준

각 단계에서 무엇을 만들어야 하나요?

0

시작 및 자료 수집

기준 확보

기존 ZIP 기획 자료, Canvas 관련 요구, 사용자 답변, Sandbox 시험 결과를 모아 서로 다른 출처를 구분합니다.

넘어가는 기준: 만들고자 하는 도구의 기본 방향과 다음 핵심 질문을 알 수 있음. 이 기준은 충족했습니다.

1

프로젝트 정의

방향 확보

Windows Obsidian Canvas에서 카드와 같은 공간에 그림을 그릴 수 있게 한다는 목적, 주 사용자와 사용 환경을 정리합니다.

넘어가는 기준: 누가 어디서 어떤 문제를 해결하려는지 설명할 수 있음. 현재 자료로 설명 가능합니다.

2

요구사항 정의

기준선 확보·보완 중

그리기·레이어·색 혼합·브러시 가져오기·저장 등 원하는 결과와 제외 항목을 정리합니다. 기능 이름이 있다고 세부 동작까지 확정된 것은 아닙니다.

남은 일: 사용 흐름을 만들면서 빠진 요구를 보완하고, 필수·선택·후속·제외를 다시 점검합니다.

3

사용 구조 설계

지금 여기

Canvas를 연 뒤 도구를 고르고, 그림을 만들고, 레이어를 바꾸고, 내용을 수정하고, 저장·재실행하는 순서를 실제 화면 기준으로 이어 붙입니다.

넘어가는 기준: 주요 작업마다 “어디서 시작 → 무엇을 누름 → 무엇이 보임 → 다음 행동 → 최종 결과”가 빠짐없이 설명됨. 현재는 일부 흐름만 초안입니다.

4

기능 설계

다음 중심 단계

브러시·지우개·색 혼합·프리셋·레이어·선택·도형·문자 등의 기능을 사용 조건, 행동, 결과, 상태 변화로 풀어냅니다. CSP 참고 동작과 사용자 고유 결정을 구분합니다.

넘어가는 기준: 핵심 요구를 만족하는 기능 구조와 주요 동작이 정의됨. 현재는 기능 목록과 일부 사용 예시만 있습니다.

5

UI·데이터·시스템 동작 설계

상세 설계 필요

왼쪽 도구 막대, 브러시 패널, 오른쪽 레이어 패널의 버튼·메뉴·선택·피드백을 정합니다. Canvas별 그림과 Vault 공용 브러시, 저장·복원 관계도 연결합니다.

넘어가는 기준: 버튼을 누른 뒤의 화면과 데이터 상태를 구현 담당자가 해석 없이 알 수 있음. 현재 HTML은 UI 모형일 뿐입니다.

6

예외·제약·품질 설계

위험 기록만 일부

저장 중 전환, 삭제·복원, 지원하지 않는 ABR 속성, 대형 Canvas 반응성 등 실제로 중요한 실패와 품질 기준을 정합니다.

넘어가는 기준: 중요한 손실·실패 때 무엇이 남고 어떻게 복구하며, 어느 수준을 통과로 볼지 설명됨. Sandbox 시험 일부가 있어도 제품 품질 설계는 미완료입니다.

7

범위 및 완료 기준 확정

아직 이름 붙일 단계 아님

기능과 UI가 구체화된 뒤 첫 사용 버전과 후속 버전에 무엇을 넣을지, 사용자가 어떤 결과를 보면 완료인지 최종 결정합니다.

넘어가는 기준: 포함·후속·제외와 기능별 완료 조건이 모순 없이 정리됨. 개인용·단계적 진행 답변은 여기서 다시 대조할 참고 결정입니다.

8

전체 검증 및 최종 기획서 완성

미착수

처음부터 끝까지 가상의 사용 흐름을 따라가며 빠진 기능, 충돌, 미결정을 점검하고 개발자가 사용할 최종 기획서로 묶습니다.

끝나는 기준: 중요한 공백과 충돌을 해결하거나 명시적으로 보류하고, 최종 기획서 작성 여부를 사용자에게 확인함. 현재 그 상태가 아닙니다.

바로 다음 작업

기능 이름보다 실제 사용 순서부터

브러시 선택→Canvas에 그리기→레이어·색 조절→수정·되돌리기→저장·다시 열기
지금 채울 것

각 행동의 시작 화면, 누르는 버튼, 작업 중 표시, 끝난 뒤 결과, Canvas 카드와 그림의 차이.

그다음 채울 것

각 기능의 세부 동작·설정과 UI 상태, 프리셋·레이어·Canvas 사이의 데이터 관계.

구현 가능성 시험은 별도 증거입니다. 브러시 시험판에서 작동하고 사용자도 렉 감소를 확인했지만, 그것만으로 위 기획 단계나 제품 기능을 완료 처리하지 않습니다.
