# Markdown 드로잉

1.0.20부터 본체에 포함됩니다. 본체의 main.js, manifest.json, styles.css만 설치하면 됩니다. 별도 MD 플러그인은 필요하지 않습니다.

기존 MD의 data.json과 그림 파일은 삭제하지 않습니다. 필기 연결 정보는 본체 폴더의 markdown-data.json으로 옮기며 원본 백업도 보존합니다. 기존 MD 추가 기능은 중복 실행을 막기 위해 비활성화합니다. 기존 사용자 지정 MD 단축키도 새 명령으로 옮깁니다.

MD 문서에서 왼쪽 펜 버튼 또는 Ctrl+Alt+D로 그리기와 타이핑을 전환합니다. 그리기 중 B는 브러시 파이 메뉴, E는 지우개 파이 메뉴이며 같은 키를 다시 누르면 닫힙니다. 툴바 아이콘을 직접 누르면 기존 패널이 열립니다. Ctrl+Alt+C는 색상, Ctrl+Alt+B는 브러시 상세, Ctrl+Alt+Q는 지정 도구, Ctrl+Alt+N은 네비게이터입니다. 사용자 지정 단축키가 있으면 그 설정이 우선합니다.

우클릭 드래그와 Alt+우클릭 드래그로 이동하고 Ctrl+우클릭 드래그로 확대·축소합니다. 필기는 문서 고정 좌표에 저장됩니다. Canvas 카드 안에 MD 필기를 표시하는 기능은 포함하지 않습니다.
