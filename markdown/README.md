# 옵시디언 드로잉 툴바 · MD

같은 저장소의 옵시디언 드로잉 툴바 본체와 함께 사용하는 Markdown 필기 플러그인입니다. 본체 1.0.19 이상을 먼저 설치하고 활성화하세요. 기존 실험판의 플러그인 ID `ink-anchor-prototype`을 유지하므로 설정과 그림 연결을 이어서 사용합니다.

## 설치

이 저장소의 최신 본체 Release에 첨부한 `markdown-drawing-0.0.23.zip`을 풀고, `main.js`, `manifest.json`, `styles.css` 세 파일을 Vault의 `.obsidian/plugins/ink-anchor-prototype/` 폴더에 넣습니다. Obsidian을 재시작한 뒤 커뮤니티 플러그인에서 **옵시디언 드로잉 툴바 · MD**를 켜세요. 업데이트할 때 기존 `data.json`은 보존합니다.

동일 저장소의 `md-0.0.23` Release에도 MD용 세 파일을 제공합니다. BRAT에서 특정 버전 설치로 받을 수 있지만, BRAT은 같은 저장소의 본체와 MD를 서로 다른 자동 업데이트 항목으로 추적하지 못합니다. 본체는 BRAT의 최신 버전 업데이트를 사용하고 MD는 ZIP으로 업데이트하는 방식을 권장합니다.

## 사용

- `Ctrl+Alt+D`: 그리기와 타이핑 전환. 타이핑으로 돌아갈 때 원래 편집 배치와 스크롤을 복원합니다.
- 그리기 중 `B` / `E`: 브러시 / 지우개 파이 메뉴. 다시 누르면 닫힙니다. 툴바 아이콘은 기존 목록을 엽니다.
- `Ctrl+Alt+B`: 브러시 상세 설정. 필압 그래프의 중간 점을 밖으로 끌어 놓으면 삭제합니다. 양 끝점은 유지됩니다.
- 우클릭 또는 `Alt+우클릭` 드래그: 화면 이동. `Ctrl+우클릭` 좌우 드래그: 확대·축소.
- `Ctrl+Alt+왼쪽` 드래그: 브러시 크기 조절. `Ctrl+Alt+N`: 문서·필기 네비게이터.

필기는 문서 좌표에 고정됩니다. 글 수정에 따라 필기를 이동시키는 기능은 없습니다. 실제 그림 데이터는 Vault의 `.canvas-drawing`에, 문서 연결 정보는 이 플러그인의 `data.json`에 저장됩니다. Markdown 파일만 복사하면 필기는 함께 이동하지 않으므로 백업 시 이 폴더와 설정 파일도 보존하세요.

## 빌드

저장소 루트에서 `npm install` 후 `npm run build:markdown`을 실행합니다. 공유 Drawing 소스와 함께 번들링하며 결과는 `dist-markdown/`에 생성됩니다.
